**Playlist Canvas는 PC에 있는 음악, 이미지, 영상과 가사를 조합해 플레이리스트 영상을 만드는 무료 Windows 프로그램입니다.** MP4·MOV·MKV 영상, 오디오만 저장하기, LRC·SRT 자막 내보내기를 지원합니다. 디자인 프리셋을 골라 시작하고, 화면에서 요소를 끌어 배치한 뒤 음악과 함께 미리보며 완성할 수 있습니다. 코딩 지식이나 별도의 Python 설치는 필요하지 않습니다.

**이 프로젝트는 ChatGPT Codex와 Claude Code를 활용하는 바이브코딩(Vibe Coding) 프로젝트입니다.** 사람이 아이디어와 제작 방향을 정하고, AI와 대화하며 프로그램을 구현합니다.

## 어떤 영상을 만들 수 있나요?

| 만들고 싶은 영상 | 사용할 수 있는 기능 |
| --- | --- |
| 여러 곡을 이어 듣는 플레이리스트 | 음악 순서 편집, 곡 제목·아티스트·앨범 커버 자동 표시, 트랙 목록과 진행 막대 |
| 노래에 맞춰 가사가 나오는 영상 | LRC·SRT·VTT 불러오기, 가사 타이밍 편집, 현재 줄 강조와 자막 애니메이션 |
| 음악에 반응하는 비주얼 영상 | 막대·원형 비주얼라이저, 파형, 레벨 미터, 파티클, 음악에 반응하는 글자와 앨범 커버 |
| 분위기 있는 배경 영상 | 이미지·영상·텍스트·도형 배치, 곡마다 다른 영상, 등장·퇴장과 반복 애니메이션 |
| 곡이 자연스럽게 이어지는 믹스 | 크로스페이드, AutoMix 자동 전환, 전환 구간 직접 편집, 곡별 음량·EQ 조절 |
| 가로·세로·정사각형 영상 | 화면 비율 선택, 사용자 지정 크기, HD부터 4K까지 MP4 내보내기 |

### 프리셋으로 시작하고 내 취향대로 꾸미기

오로라, 카세트, 미드나잇, 바이닐, 노래방, 플로우, 시네마 자막, 네온 나이트 등 디자인 프리셋을 제공합니다. 미리보기로 분위기를 고른 뒤 배경, 글꼴, 색상과 배치를 바꿀 수 있습니다.

이미지·영상·글자·도형을 여러 겹으로 쌓고 위치와 크기를 조절하세요. 곡이 바뀌면 앨범 커버와 곡 정보가 함께 바뀝니다. 타임라인에서는 요소가 나타나는 시점과 표시 길이를 정할 수 있습니다.

### 음악에 맞는 가사와 자막

가사 파일을 불러오거나 가사 편집기에서 음악을 들으며 각 줄의 시간을 기록할 수 있습니다. 현재 부르는 줄을 강조하고 이전·다음 줄의 크기, 투명도, 흐림과 이동 효과를 조절하세요. 곡마다 가사가 빠르거나 늦게 나오면 타이밍을 따로 보정할 수 있습니다.

가사 요소의 **현재 줄 · 기본 → 단어별 노래방 표시 → 자동 표시**를 켜면 단어를 따라 강조 색이 채워집니다. 노래방 프리셋에는 기본으로 적용됩니다. 단어 타이밍이 포함된 Enhanced LRC의 `<분:초>` 시간을 사용하며, 일반 LRC·SRT·VTT는 기존 줄 시간과 단어 길이로 자동 추정합니다. 이 추정은 음성 인식이 아니므로 실제 보컬과 다를 수 있습니다. 미리보기와 영상 내보내기에 동일하게 적용되며, 단어 타이밍 수동 등록 기능은 아직 제공하지 않습니다.

가사 요소를 선택하고 오른쪽 **자막/가사 → 자동 노래방…**을 누르면 색상과 표시를 한 화면에서 설정할 수 있습니다. 플레이리스트에서 선택한 곡을 사용하며, 곡 선택이 없으면 가사가 있는 첫 번째 활성 곡을 사용합니다. 화면 제목에서 곡 이름을 확인하세요. 기본 버튼인 **줄 시간으로 바로 적용**은 다운로드나 오디오 인식 없이 기존 자막 시간과 단어 길이로 표시합니다. 단어 시간을 더 맞추고 싶으면 **분석 시작 → 결과 확인 → 선택 적용**을 사용하세요. 곡 정보의 **가사/자막 → 자동 노래방…**으로 열었다면 마지막에 곡 설정의 **적용**을 눌러 저장합니다.

한 자막 안의 원문·번역 줄 중 **1번째 줄만 기본 선택**하며, 2번째 줄도 실제로 부르는 가사라면 따로 선택할 수 있습니다. 선택한 줄마다 전체 줄 시간을 사용하므로 번역문이 원문의 강조 진행을 늦추지 않습니다. **줄 시간으로 바로 적용**은 기존 단어 시간을 유지하며, 인식하지 못한 단어는 주변 단어 시간과 줄 시간으로 보완합니다. 선택하지 않은 번역 줄에는 단어 강조를 적용하지 않습니다. 오디오 분석은 단어를 인식해 출력한 시점을 구간의 끝 경계로 사용하고, 앞 경계부터 강조를 채워 한 단어 늦게 시작하는 현상을 줄입니다. 기존 단어 시간이 있는 곡도 **분석 시작 / 다시 분석 → 선택한 결과 적용**으로 재계산할 수 있으며, 체크한 줄의 단어 시간만 교체합니다. 분석은 기존 가사를 문맥으로 활용하고, 절반 이상의 글자가 신뢰할 수 있는 단어로 일치하면 부분 결과를 제시합니다. 기존 줄의 시작·끝 시간은 바꾸지 않습니다. 실제 인식 내용과 구간 듣기로 결과를 확인하세요. 분석 오류나 일치하는 단어가 없어도 같은 화면에서 줄 시간 표시를 적용할 수 있습니다. 취소하면 기존 단어 시간을 유지합니다.

**자동 노래방** 화면의 **노래방 설정**에서 **도달한 가사 색 / 강조 색**을 고르고, **미도달 가사 표시**를 **별도 색상** 또는 **도달한 색의 밝기 낮추기**로 선택하세요. 같은 설정은 가사 요소의 **현재 줄 · 기본**에서도 조절할 수 있습니다. 별도 색상에서는 미도달 색을 직접 선택합니다. 밝기 방식에서는 0~1 사이의 밝기를 조절하며, 기본값 0.35는 도달한 색 밝기의 35%입니다. 글자의 불투명도는 유지합니다. 아직 부르지 않은 단어와 다음 가사는 미도달 색으로 표시하고, 도달하면 설정한 강조 색으로 채웁니다. 색상과 줄별 단어 표시는 미리보기와 영상 내보내기에 동일하게 적용됩니다.

오디오 분석은 경량 Tiny 모델만 사용합니다. **단어 강조 보정 (초)**은 분석 없이 즉시 적용됩니다. 양수는 앞당기고 음수는 늦춥니다(예: `0.20` = 0.2초 앞당김). 가사 줄 전환과 간주 시간은 바꾸지 않으며, 간주 표시 중에는 이전 가사의 단어 강조를 멈추고 보컬이 재개되는 시점부터 다시 표시합니다.

선택 사항인 오디오 분석을 처음 사용할 때 약 36 MB의 [whisper.cpp](https://github.com/ggml-org/whisper.cpp) CPU 도구와 다국어 Tiny 양자화 모델을 내려받습니다. PC에서 두 스레드로 짧은 가사 구간만 분석하고 종료하며, 오디오를 외부에 보내거나 PyTorch·GPU 런타임을 설치하지 않습니다. 일치한 단어 시간은 저장·재사용하고, 실패한 캐시는 재사용하지 않습니다. 한 구간의 인식이 실패해도 다음 구간은 계속 분석합니다. 작은 모델이므로 노래·반주에 따라 인식하지 못하는 줄이 있을 수 있습니다. 기존 줄 시간은 대략 맞아야 하며, 24초를 넘는 큐는 기존 줄 시간으로 표시합니다. 미리보기와 내보내기는 준비한 단어 시간·글자 위치·글자 모양을 재사용해 프레임마다 같은 계산을 반복하지 않습니다.

### 곡 사이를 연결하는 AutoMix

AutoMix는 곡의 박자, 조성, 보컬 구간과 분위기를 분석해 전환 위치와 방식을 자동으로 정합니다. 두 곡의 파형을 보면서 겹치는 길이와 시작 지점을 직접 바꾸고, 전환 구간을 반복해서 들을 수 있습니다. 자동 결과와 내 편집을 **A/B 비교**하고, 마음에 드는 설정은 프리셋으로 저장할 수 있습니다.

![AutoMix 편집 화면 — 두 곡의 파형을 보며 전환 위치와 겹치는 길이를 조절하고 미리듣기](app/resources/help/ko/automix_editor.png)

**AutoMix는 베타 기능입니다.** 첫 분석에는 시간이 필요하고 음악에 따라 결과가 달라지므로, 내보내기 전에 전체 믹스를 들어 보세요. 분석은 PC 안에서 진행하며 결과를 저장해 재사용합니다. 간단히 곡을 겹치려면 크로스페이드, 곡을 순서대로 재생하려면 전환 없음을 선택할 수 있습니다.

### 영상·오디오·자막으로 내보내기

내보내기 창에서 파일 형식, 이름과 저장 폴더를 따로 선택합니다. 영상은 MP4·MOV·MKV, 오디오는 MP3·M4A·WAV·FLAC·OGG로 저장할 수 있습니다. 오디오만 내보내도 곡 전환과 음량 처리는 적용됩니다.

LRC·SRT 자막은 곡의 자르기, 속도, 가사 시간 보정과 실제 믹싱 타임라인을 반영합니다. 두 곡이 겹치는 구간에는 나가는 곡의 가사를 위에, 들어오는 곡의 가사를 아래에 표시합니다. 전환 없는 자막은 FFmpeg 없이 저장할 수 있습니다.

미리보기와 가사·AutoMix 편집 화면은 블루투스 출력의 지연 가능성, 음소거, 볼륨 0, 출력 장치와 재생 오류를 안내합니다. 정확한 타이밍을 편집할 때는 유선 출력을 권장합니다.

## 설치 전에 확인하세요

| 항목 | 안내 |
| --- | --- |
| 운영체제 | Windows 64비트용입니다. 기준 환경은 Windows 11입니다. |
| 사용 언어 | 한국어·영어를 지원합니다. |
| 준비할 파일 | PC에 저장된 음악 파일을 준비하세요. 이미지·영상·가사는 원하는 경우 추가합니다. |
| 필요한 구성요소 | 영상 내보내기와 믹스 미리보기 등에 FFmpeg가 필요합니다. 앱 안에서 다운로드하고 설치할 수 있습니다. |
| 인터넷 연결 | 프로그램·FFmpeg 다운로드와 업데이트 확인에 필요합니다. 설치 후 로컬 파일로 편집·분석·내보내기할 수 있습니다. |
| 작업 시간과 공간 | 긴 영상, 많은 효과, 4K·높은 프레임 레이트는 더 많은 시간과 저장 공간을 사용합니다. 내보내기 창에서 예상 필요 공간을 확인할 수 있습니다. |

이 프로그램은 **직접 준비한 음악 파일로 영상을 만드는 도구**입니다. M3U·M3U8 목록도 로컬 음악 파일을 가져오는 용도로 사용하며, 웹 스트리밍 주소는 건너뜁니다. 화면에 추가한 영상 클립의 소리는 사용하지 않고, 최종 영상의 음악은 플레이리스트로 구성합니다.

## 다운로드와 설치

1. [공식 다운로드 페이지](https://github.com/tharu8813/Playlist-Canvas/releases/latest)를 엽니다.
2. **Assets**에서 이름이 `setup.exe`로 끝나는 Windows 설치 파일을 받습니다. 파일명 예시는 `Playlist.Canvas-1.3.1.2-setup.exe`입니다. `Source code`는 소스 코드 압축 파일입니다.
3. 설치 파일을 실행해 언어와 설치 위치를 선택한 뒤, 시작 메뉴나 바탕 화면에서 **Playlist Canvas**를 엽니다.
   기본 설치 위치는 `%LOCALAPPDATA%\Programs\Playlist Canvas`이며 관리자 권한을 요청하지 않습니다.
4. 프로그램의 **도구 → 설정 → FFmpeg**에서 **(권장)** 버전을 고르고 **선택 버전 다운로드 및 설치**를 누릅니다. 다운로드와 설치가 끝나면 자동으로 적용됩니다.

FFmpeg는 음악과 화면을 합쳐 영상 파일로 만드는 구성요소이며, 프로그램 설치 파일에는 포함되지 않습니다. **MP4 내보내기, 내보내기 품질의 믹스 미리보기, 박자 기반 AutoMix 분석·미리듣기와 EQ 미리듣기**를 사용하려면 설치해 주세요. 기본 크로스페이드 미리보기는 FFmpeg 없이도 바로 재생하며, AutoMix 준비 중에도 기본 크로스페이드로 연결합니다. 이미 설치한 FFmpeg가 있다면 같은 설정 화면에서 `ffmpeg.exe`를 지정할 수 있습니다.

## 첫 영상 만들기

1. **새 프로젝트 만들기** — 이름, 화면 비율과 디자인 프리셋을 고릅니다. 일반 가로 영상은 16:9, 세로 영상은 9:16으로 시작할 수 있습니다.
2. **음악 추가하기** — 음악 파일을 플레이리스트에 넣고 원하는 순서로 정렬합니다. 곡 전환은 없음·크로스페이드·AutoMix 중에서 선택합니다.
3. **화면 꾸미기** — 요소 탭에서 배경, 앨범 커버, 제목, 가사와 비주얼라이저를 추가합니다. 캔버스에서 끌어 배치하고 오른쪽 속성에서 모양과 효과를 조절합니다.
4. **음악과 함께 확인하기** — 하단 **미리보기** 탭에서 전체 영상을 재생합니다. 가사 타이밍, 곡 사이 전환과 음량을 확인하세요.
5. **프로젝트 저장하기** — `Ctrl+S`로 `.pvsproj` 파일을 저장합니다. 미디어를 프로젝트에 포함하면 다른 PC로 옮겨 이어서 편집하기 편합니다.
6. **MP4 내보내기** — 오른쪽 위 **내보내기**(`Ctrl+E`)에서 저장 위치와 화질을 선택합니다. 처음에는 **권장 · 대부분의 영상**, **Full HD, 30 FPS**로 시작해 보세요.

**프로젝트 저장은 편집 내용을 보관하고, MP4 내보내기는 완성된 영상을 만듭니다.** 나중에 수정할 수 있도록 프로젝트 파일도 함께 보관하세요. 작업 중 자동 저장과 비정상 종료 후 복구를 지원합니다.

## 지원하는 파일

| 용도 | 형식 |
| --- | --- |
| 음악 | MP3, WAV, FLAC, AAC, M4A, OGG |
| 이미지 | JPG, JPEG, PNG, WebP, SVG |
| 화면에 넣는 영상 | MP4, MOV, MKV, WebM, AVI, M4V |
| 가사·자막 | LRC, SRT, VTT |
| 음악 목록 | M3U·M3U8 가져오기, M3U8 내보내기 |
| 편집 프로젝트 | `.pvsproj` |
| 완성 영상 | MP4 |

## 사용 중 도움이 필요하면

**F1**을 누르면 현재 화면에 맞는 그림 설명과 사용법이 열립니다. 도움말은 인터넷 없이 사용할 수 있고, 검색으로 필요한 내용을 찾을 수 있습니다.

| 이런 경우 | 이렇게 해 보세요 |
| --- | --- |
| 내보내기나 믹스 미리보기가 시작되지 않아요 | **도구 → 설정 → FFmpeg**에서 설치 상태를 확인하세요. |
| 미리보기가 끊기거나 내보내기가 너무 오래 걸려요 | 미리보기 화질을 낮추거나 효과를 줄여 보세요. 미리보기 화질을 낮춰도 최종 영상 화질은 유지됩니다. 내보내기는 Full HD, 30 FPS로 시작해 보세요. |
| GPU 내보내기에 실패해요 | 내보내기 설정에서 **CPU H.264**를 선택해 보세요. |

문제가 계속되면 **도움말 → 프로그램 정보**에서 진단 정보를 복사하고, 작업 단계와 오류 메시지를 [문제 신고](https://github.com/tharu8813/Playlist-Canvas/issues)에 남겨 주세요. 업데이트는 **도움말 → 업데이트 확인**에서 확인할 수 있습니다.

**다운로드 및 업데이트**를 한 번 누르면 파일 검증 → 작업 복구본 보관 → 종료 → 자동 설치 → 재실행 → 작업 복구까지 추가 클릭 없이 진행합니다. 진행 중인 내보내기·저장·도구 다운로드는 먼저 끝날 때까지 기다립니다. 원본 프로젝트 파일을 덮어쓰지 않으며, 저장되지 않은 작업과 기존 프로젝트 경로를 유지합니다. 이전 관리자 설치본은 그대로 두고 사용자 폴더에 새 버전을 설치합니다. 설치 실패의 상세 내용은 내려받은 Setup 옆의 `.install.log`에 남습니다.
