# Playlist Canvas 1.3.1.3

1.3.1.2 이후 내보내기와 긴 프로젝트의 처리 비용을 줄이고, 편집·저장·업데이트의 안정성을 개선했습니다.

## 내보내기 속도와 메모리

- 정적 배경과 작은 움직이는 전경을 분리해, 진행 바 등을 갱신할 때 전체 화면을 다시 그리는 작업을 줄였습니다. 큰 동적 영역은 기존 직접 출력 경로를 유지합니다.
- 영상의 기본 색보정 필터를 생략하고, 둥근 모서리와 페이드는 알파 영역을 중심으로 계산해 합성 비용을 줄였습니다.
- 긴 영상의 프레임 일정을 필요한 순서대로 생성합니다. 전체 프레임 목록을 먼저 메모리에 보관하지 않으며, 중간 영상·PNG·파이프 출력 모두 같은 일정을 사용합니다.
- 비주얼라이저를 중간 영상 파일 없이 최종 인코더로 직접 전달합니다. 파티클·파형·레벨 미터만 사용하는 경우 불필요한 주파수 분석도 생략합니다.
- 같은 내보내기에서 반복되는 오디오 파일의 음악 반응 분석을 재사용하고, 실시간 출력에서 중간 파일 방식으로 재시도할 때도 완료된 분석 결과를 유지합니다.
- 1080p·30fps·20초 합성 프로젝트의 전체 내보내기 비교에서는 실행 순서에 따라 약 16~29%의 시간 감소를 확인했습니다. 실제 효과는 프로젝트 구성과 장비에 따라 다릅니다. 출력 해상도와 FPS를 낮추는 방식의 개선은 아닙니다.

## 프로젝트 편집과 저장

- 실행취소 기록에서 변경되지 않은 데이터를 재사용해 긴 플레이리스트의 복사 비용과 메모리 사용을 줄였습니다.
- 프로젝트를 다시 열 때 정상인 추출 미디어 캐시를 재사용하고, 누락되거나 손상된 파일만 복구합니다. 복구 중 취소 시 기존 미디어를 보존합니다.
- 여러 창에서 같은 프로젝트를 편집할 때 자동 복구본이 서로 덮어쓰거나 지워지는 문제와, 저장 이후 오래된 자동 저장 작업이 복구본을 다시 만드는 문제를 수정했습니다.
- 누락된 미디어를 다시 연결한 변경을 저장 대상으로 유지하고, 사용자가 내보내기에서 제외한 곡의 상태를 보존합니다.
- 캔버스 이동·크기 조절의 정렬 동작과 안내선을 개선했습니다. 여러 요소를 함께 움직일 때 상대 위치를 유지하고, 확대 배율과 작은 포인터 흔들림을 반영합니다.

## 색상과 가사

- 색상 편집에서 HEX 입력 확인, 투명도 조절과 퍼스널 컬러 전환을 개선했습니다. 그림자 전용 색상 설정을 구분합니다.
- 음악 반응 텍스트·가사의 미리보기와 내보내기 설정 적용을 보완했습니다.
- 노래방 가사의 색상·타이밍 설정을 별도 그룹으로 정리하고, 전체 가사 시간 보정과 단어 강조 시간 보정을 구분했습니다. 노래방 가사는 계속 베타 기능입니다.
- VTT/SRT 가사의 시간 형식 검증을 강화했습니다. 자막 내보내기에 가사 요소의 시간 보정을 반영하고, 겹치는 가사 구간의 처리를 미리보기와 맞췄습니다.

## 설치와 자동 업데이트

- 새 설치의 기본 경로를 Program Files로 정리했습니다. 자동 업데이트는 현재 설치 경로를 유지합니다.
- 설치 프로그램의 준비 신호를 받은 뒤 작업을 백업하고 종료하도록 개선했습니다. 권한 요청을 취소하면 편집기를 유지하고, 설치 성공 후 저장된 작업으로 다시 시작합니다.
- 제거 시 설치 폴더에 별도로 보관한 사용자 파일을 삭제하지 않도록 수정했습니다.
- 도움말과 배포 검증 항목을 갱신했습니다.

## 참고

- 합성 경로와 불필요한 색공간 변환을 정리하면서 이전 버전과 출력 파일의 바이트 및 일부 픽셀의 반올림 결과가 다를 수 있습니다.
- Windows 설치 파일을 실행하면 관리자 권한 확인 창이 표시될 수 있습니다. FFmpeg는 기존과 같이 앱 설정에서 검증된 배포본을 내려받아 사용합니다.
