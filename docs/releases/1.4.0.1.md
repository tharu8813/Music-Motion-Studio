# Music Motion Studio 1.4.0.1

실제 프로젝트 화면을 보면서 곡 시작·곡 끝 모션을 직접 만들 수 있습니다. 가사 번역 작업을 이어서 검토하기 편리해지고, 전체 화면 미리보기와 업데이트 설치 중 불편도 줄였습니다.

## 새로운 기능

- **화면에서 만드는 키프레임 애니메이션:** 요소를 선택한 뒤 **애니메이션 → 곡 시작 또는 곡 끝 → 키프레임으로 만들기... → 키프레임 편집...**을 열어 보세요. 실제 배경·앨범 커버·곡 정보를 보면서 이동·크기·회전을 조절하고, 시작과 끝 모션을 각각 저장할 수 있습니다.
- **속성별 타이밍과 곡선:** X·Y·크기·회전·투명도의 키프레임을 따로 편집합니다. 두 점 사이의 베지어 곡선과 그래프 모양 프리셋을 고를 수 있고, 트랙을 꺼도 기존 키프레임은 남습니다.
- **빠르게 반복하며 편집:** 슬라이더와 숫자 입력, 재생·반복·실행 취소, 원본 비교·가이드를 제공합니다. 휠로 확대하고 빈 곳·가운데 버튼·Space+드래그로 화면을 이동할 수 있습니다. 첫 실행 안내와 F1 도움말, Shift+F1 단축키 목록도 추가했습니다.
- **가사 번역 작업 공간:** 클라우드 LLM·로컬 LLM·로컬 번역 모델을 선택하고, 원문과 번역을 같은 표에서 비교·수정합니다. 적용할 행을 고르거나 선택한 행·실패한 행만 다시 번역할 수 있으며, 초안을 저장해 창을 닫은 뒤에도 이어서 작업할 수 있습니다. 서비스 준비와 고급 설정은 별도 창에서 관리합니다.
- **로컬 모델 관리:** Ollama 실행 구성요소 설치와 모델 다운로드·이어받기·관리, LM Studio 연결을 지원합니다. 로컬 번역 모델은 원문·번역 언어에 맞는 모델의 자동 설치를 안내합니다.

## 개선 및 오류 수정

- **찾기 쉬운 속성창:** 콘텐츠·배치 및 변형·디자인·애니메이션·고급으로 설정을 정리했습니다. 새 모션은 별도 편집 창에서 만들고, 작은 화면에서는 필요한 목록을 스크롤할 수 있습니다.
- **미리보기와 출력의 움직임:** 일부 요소의 투명도가 다르게 보이거나, GPU 미리보기의 회전 방향이 달라지던 문제를 수정했습니다. 긴 키프레임 애니메이션과 일부 FFmpeg 환경에서 내보내기가 실패할 수 있던 문제도 보완했습니다.
- **전체 화면 조작:** 마우스가 사라진 뒤 다시 나타나지 않거나 Alt+Tab으로 돌아왔을 때 재생 도구가 제대로 복원되지 않던 상황을 수정했습니다.
- **업데이트 설치 안내:** 자동 업데이트 설치 중 진행률을 표시하고, 권한 요청을 취소하면 편집기를 유지합니다. 기존 설치 위치와 작업 복구를 이어가도록 개선했습니다.
- **한국어·영어 도움말:** 새 키프레임 편집기·단축키·이전 데이터 호환·배경 효과를 설명하고, 개편된 속성창과 계정 설정·영상 출력 제한에 맞춰 안내와 화면 이미지를 갱신했습니다.

## 설치 및 참고

- Windows 64비트용입니다. 이 릴리스의 `setup.exe` 설치 파일을 실행하거나 앱의 자동 업데이트를 이용하세요. 설치 시 관리자 권한을 요청합니다. Python을 따로 설치할 필요는 없습니다.
- FFmpeg는 설치 파일에 포함되지 않습니다. 영상·오디오 내보내기와 AutoMix 분석·미리듣기 등에 필요하며 **도구 → 설정 → FFmpeg**에서 설치하거나 경로를 지정할 수 있습니다.
- AutoMix는 베타 기능입니다. 곡에 따라 결과가 다르므로 내보내기 전에 전체 믹스를 확인해 주세요.
- 키프레임 편집 창의 영상은 현재 프레임 또는 정지 화면이며, 음악 반응은 예시입니다. 효과 밖 미리보기는 효과 길이의 절반으로, 시작 효과 뒤·끝 효과 앞에만 표시하며 해당 구간은 편집할 수 없습니다. 실제 짧은 곡이나 요소 표시 시간, 믹스 전환에 따라 효과 길이가 달라질 수 있습니다.
- 기존 전체 영상·특정 곡·곡별 키프레임 데이터는 보존합니다. 데이터가 있는 프로젝트에는 **이전 키프레임 (호환)** 보기가 나타나며, 새 모션과 중복 재생하지 않습니다. 이전 키프레임이 활성화되어 있으면 새 편집기를 적용할 때 재생 중지·데이터 보존을 확인합니다. 기존 프로젝트는 별도 사본으로 보관해 주세요.
- 영상 요소의 등장·퇴장 내보내기는 없음·페이드·사용자 지정 키프레임을 지원합니다. 다른 등장·퇴장 프리셋과 반복 모션은 영상 요소에서 내보낼 수 없습니다.
- 클라우드 번역은 선택한 서비스로 가사를 보내며 요금이나 구독 한도가 적용될 수 있습니다. 로컬 모델은 첫 준비에 인터넷과 저장 공간이 필요합니다. 로컬 번역 모델은 LLM이 아니므로 가사·비유·문맥의 번역 품질이 낮을 수 있습니다.
