# Music Motion Studio 1.4.1.1

이번 업데이트는 **1.4.1.0 이후의 디자인·편집 도구 확장, 내보내기 및 프로젝트 관리 개선, 오류 복구 강화**를 담았습니다. 화면 요소를 더 다양하게 꾸미고 작업 파일을 쉽게 옮길 수 있으며, 문제가 발생했을 때 원인을 확인하고 안전하게 종료하기 편해졌습니다.

## 새로운 기능

- **11가지 요소 디자인 추가:** 진행 바에 **Segments(12칸 분할)·Rail(마커 트랙)·Neon(빛나는 라인)**, 현재 재생 카드에 **Outline·Accent·Gradient**, 트랙 목록에 **Spotlight·Outline·Stripes**, 앨범 커버에 **Vinyl·Filmstrip**을 추가했습니다. 디자인 선택 메뉴에서 미리 본 뒤 적용할 수 있습니다.
- **M3U8 플레이리스트 폴더 내보내기:** 내보내기에 포함된 음악의 사본과 M3U8 목록을 하나의 폴더로 저장할 수 있습니다. 폴더 전체를 다른 PC로 옮기기 편리합니다.
- **프로젝트 콘텐츠 개별 내보내기:** 프로젝트 콘텐츠 목록에서 파일을 우클릭해 원래 파일명으로 사본을 내보낼 수 있습니다. 프로젝트에 포함된 미디어도 지원합니다.
- **곡별 가사 파일 내보내기:** 곡 정보·설정에서 현재 연결된 가사를 LRC·SRT로 저장할 수 있고, 단어 또는 음절별 시간 정보가 있는 가사는 TTML로도 저장할 수 있습니다. 곡의 시간 오프셋을 반영합니다.
- **상세 크래시 보고서:** 오류가 발생하면 전체 오류 추적 정보와 함께 운영체제, CPU, 메모리, 화면·DPI, GPU 드라이버, 프로그램 실행 환경, 프로젝트·저장·내보내기 상태, 최근 로그 등 진단 정보를 기록합니다. 개별 보고서는 최대 50개까지 보관하며 보고서 경로를 확인할 수 있습니다.
- **연속 오류 시 안전 종료 메뉴:** 90초 안에 오류가 두 번 이상 발생하면 **프로젝트 저장 후 종료 / 다른 이름으로 저장 후 종료 / 저장하지 않고 종료 / 강제 종료**를 선택할 수 있습니다. 저장이 실패하거나 취소되면 안전하지 않은 종료를 막습니다.
- **크래시 테스트 도구:** **설정 → 유지 관리 → 프로그램 관리**에서 6가지 오류 유형을 선택해 보고 체계를 시험할 수 있습니다. 실제 프로세스를 비정상 종료하는 항목도 있으므로 테스트용 프로젝트에서만 사용하세요.

## 편집 및 사용성 개선

- **화면 요소 속성 확장:** 오디오 파형의 점 개수와 선 두께를 조절할 수 있습니다. 영상 무작위 반복의 시드를 직접 설정해 미리보기와 내보내기에서 같은 재생 순서를 유지할 수 있습니다.
- **시간 표시 형식 추가:** 시간 표시 요소에서 **자동 / 분:초 / 시:분:초**를 선택할 수 있고, 실시간 미리보기와 최종 영상의 표시를 일치시켰습니다.
- **그림자 색상 설정 확장:** 텍스트뿐 아니라 다른 화면 요소에서도 그림자용 퍼스널 컬러 설정에 접근할 수 있습니다.
- **디자인·애니메이션 미리보기 강화:** 파형, 진행 바, 그라데이션, 글자색과 가사 효과의 썸네일을 실제 캔버스 표현에 맞췄습니다. 가사 전환 미리보기에는 이전·현재·다음 가사와 실제 효과를 보여 주며, 갤러리 시연 속도도 비교하기 쉽게 조정했습니다. 이는 실제 영상의 애니메이션 속도를 바꾸지 않습니다.
- **프로젝트 파일 찾기 개선:** 미디어가 빠진 프로젝트를 열 때 **폴더에서 찾기**로 이름이 일치하는 파일을 한꺼번에 연결할 수 있습니다. 원본 파일이 없으면 누락된 파일을 제외하고 프로젝트를 열 수 있으며, 프로젝트에 저장된 가사 데이터는 보존합니다.
- **프로젝트 열기 반응성:** 대용량 프로젝트의 불러오기 진행 상태와 취소 동작을 개선하고, 앨범 커버를 준비하는 단계를 구분했습니다.
- **캔버스 조작 안정성:** 확대·축소와 화면 맞춤 동작, 여러 요소를 선택해 크기를 조절하는 동작, 포커스 전환 시 마우스 제스처 처리를 다듬었습니다.
- **도움말 개선:** 한국어·영어 도움말의 설명과 화면 이미지를 갱신하고, 단축키·애니메이션·자막 번역·프로젝트·내보내기 안내를 보강했습니다. 오래된 도움말 항목을 알아볼 수 있도록 수정 이력도 표시합니다.

## 오류 수정 및 안정성 강화

- **가사 내보내기의 '오류 13' 해결:** 시간이 지정된 빈 가사 줄 때문에 영상 내보내기 준비 중 **KeyError: 13**이 발생할 수 있던 문제를 수정했습니다. 빈 줄의 내부 레이아웃 위치를 유지해 가사가 보이지 않더라도 줄 번호가 어긋나지 않도록 했습니다.
- **트랙 목록 잘림·넘침 수정:** 표시 행 수를 실제 요소 크기에 맞춰 제한하고 글자나 행이 요소 영역 밖으로 그려지지 않도록 수정했습니다. 신규 목록 디자인도 같은 계산을 사용합니다.
- **Rail 진행 바 마커 중복 수정:** 진행 핸들을 숨겨도 기본 마커가 남거나, 선택한 노브와 중복 표시되는 문제를 수정했습니다.
- **자동 복구 경험 개선:** 일반 실행에서 **'저장되지 않은 작업을 복구할까요?'** 확인창 없이 복구 가능한 작업 내용을 자동으로 불러오도록 변경했습니다. 저장되지 않은 상태와 복구본은 유지합니다.
- **오래된 자동 저장 결과 방지:** 취소되거나 더 최신 작업으로 대체된 자동 저장이 성공 메시지를 표시하거나 이전 복구 파일을 다시 생성하지 않도록 수정했습니다.
- **저장·복구 충돌 방지:** 다른 저장이 진행 중일 때 **다른 이름으로 저장**을 잘못 성공 처리하는 문제를 수정하고, 복구 롤백에 실패했을 때 오류를 명확하게 안내하도록 개선했습니다.
- **업데이트 설치 정체 개선:** 구형 1.4.0.1 편집기가 창만 닫히고 프로세스는 남아 설치가 멈추는 상황에 대비했습니다. 설치 프로그램은 복구본과 실행 경로를 확인하고 사용자 동의를 받은 경우에만 남은 프로세스 종료를 시도합니다. 새 편집기의 종료 재시도 동작도 개선했습니다.

## 설치 및 호환성

- **Windows 64비트용**입니다. 정식 배포 전에는 아직 1.4.1.1 설치 파일이 공개되지 않았을 수 있습니다. 공개된 후에는 공식 GitHub 릴리즈에 첨부된 설치 파일 또는 앱의 정식 업데이트를 이용하세요.
- **프로젝트 형식 안내:** 프로젝트 열기·저장은 **.pvsproj** 파일을 기준으로 통일되었습니다. 이전 버전에서 사용한 **JSON 프로젝트 파일은 최신 버전에서 직접 여는 경로가 제거**되었으므로, 오래된 파일이 있다면 이전 버전에서 .pvsproj로 저장한 뒤 업데이트하세요. 현재 .pvsproj 파일을 자동 초기화하거나 내용 구조를 강제 변환하지 않습니다.
- **기존 프로젝트 보존:** 중요한 작업은 업데이트 전에 .pvsproj 사본으로 백업하는 것을 권장합니다. 설치 프로그램은 이전 버전의 사용자 설정과 복구 데이터를 보존하도록 설계되어 있습니다.
- **Rust GPU 엔진:** 지원되는 Windows·NVIDIA GPU 환경에서 H.264 MP4를 내보낼 수 있습니다. 그 외 형식과 환경에서는 FFmpeg 엔진을 이용하세요. FFmpeg는 설치 파일에 포함되지 않으며 프로그램 설정에서 설치할 수 있습니다.
- **AutoMix는 베타 기능**입니다. 프로젝트나 PC 환경에 따라 영상 처리 성능과 분석 결과가 달라질 수 있습니다.
- **배포 전 확인 권장:** 실제 Windows에서 설치·업그레이드, 가사 포함 영상 내보내기, 디자인 갤러리, 자동 복구, 각종 크래시 테스트를 확인해야 합니다. 코드 병합 자체가 설치본 QA 완료를 의미하지는 않습니다.
