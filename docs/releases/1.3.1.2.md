# Playlist Canvas 1.3.1.2

많은 곡을 넣었을 때의 미리보기 응답성을 개선하고, 가사 편집과 노래방 표시 기능을 확대했습니다.

## 미리보기와 곡 전환

- 전체 곡의 앨범 커버를 화면 스레드에서 읽던 병목을 개선했습니다. 미리보기 화면이 먼저 열리고 커버는 백그라운드에서 순차 표시됩니다.
- 믹스가 준비되거나 언어가 바뀔 때 기존 곡 목록과 커버를 재사용합니다. 긴 플레이리스트의 재생 구간 탐색 비용도 줄였습니다.
- 크로스페이드와 AutoMix의 최종 믹스를 준비하는 동안 두 오디오 플레이어로 곡 전환을 미리들을 수 있습니다. 준비된 믹스로 전환할 때 재생 위치를 유지합니다.
- 타임라인 드래그 중 화면 갱신과 오디오 이동 요청을 정리하고, 부하에 따른 미리보기 품질 조절을 개선했습니다.

## 가사와 노래방 표시

- **노래방 가사는 베타 버전 기능입니다.** 가사 속성, 자동 노래방 버튼과 설정창에 베타 표시를 추가했습니다.
- 단어별 가사 강조, 아직 부르지 않은 가사의 색상·밝기와 단어 강조 시간 보정을 지원합니다.
- 기존 가사 줄 시간으로 바로 적용하거나, 선택한 줄을 오디오와 맞춰 단어 시간을 준비할 수 있습니다. 선택한 줄의 가사와 색상·표시 설정을 함께 적용합니다.
- 여러 줄 가사와 간주 구간의 강조 처리, 가사 전환 효과·줄별 스타일과 관련 설정 화면을 개선했습니다.

## 편집과 저장

- 음악 가져오기, 곡 목록 갱신과 가사 편집의 불필요한 반복 작업을 줄였습니다.
- 자동 저장을 백그라운드에서 처리하고 곡별 가사 변경의 저장·복구 처리를 개선했습니다.
- 자동 업데이트가 기존 앱 종료 후 설치 파일을 갱신하고, 성공한 경우 저장된 작업으로 다시 시작하도록 개선했습니다.
- 도움말과 사용 안내를 현재 기능에 맞춰 갱신했습니다.
