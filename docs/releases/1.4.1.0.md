# Music Motion Studio 1.4.1.0

이번 업데이트에서는 새로운 **Rust GPU 내보내기 엔진**을 추가하고, 오디오 조절과 미리보기·프로젝트 설정 화면을 크게 개선했습니다. 가사 동기화와 영상 저장 과정의 오류도 수정했습니다.

## 새로운 기능

- **Rust GPU 영상 내보내기:** 내보내기 설정에서 기존 **FFmpeg** 외에 **Rust GPU** 엔진을 선택할 수 있습니다. 지원되는 Windows·NVIDIA GPU 환경에서 D3D11과 NVENC로 H.264 MP4 영상을 만들며, 프레임 처리와 전송 최적화는 자동으로 적용됩니다. GPU 기능을 사용할 수 없는 환경에서는 FFmpeg 경로를 이용할 수 있습니다.
- **재생 타임라인의 오디오 파형:** 전체 플레이리스트와 현재 곡 모드의 재생 막대에 음악의 크고 작은 구간을 파형으로 표시합니다. 재생 위치 이동과 곡 경계·전환 구간 표시는 그대로 사용할 수 있습니다.
- **곡별 8밴드 이퀄라이저와 베이스 조절:** 곡 정보/설정의 오디오 탭에서 기존 5밴드 대신 8밴드 EQ와 독립적인 베이스 조절을 사용할 수 있습니다. 현재 재생 위치부터 약 20초만 빠르게 미리 들으며 소리를 비교할 수 있고, 기존 프로젝트의 5밴드 설정도 이어받습니다.
- **애니메이션·디자인 미리보기 메뉴:** 관련 선택 상자를 열면 이름만 나열하는 대신 격자형 썸네일로 움직임과 디자인을 확인할 수 있습니다. 메뉴를 다시 클릭해 닫거나 미리보기 항목을 선택할 수 있으며, 일반 설정용 목록은 기존 방식으로 유지됩니다.
- **자세해진 프로젝트 정보:** 프로젝트 설정창 상단에 썸네일을 표시하고, 생성일·생성 당시 앱 버전·현재 앱 버전·파일 형식과 경로·파일 크기·마지막 수정일·곡과 요소 개수 등을 확인할 수 있습니다. 이전 프로젝트에 기록되지 않은 정보는 임의의 날짜나 버전으로 채우지 않습니다.

## 개선 및 오류 수정

- **내보내기 설정과 진행 상황:** 프로젝트 미리보기와 출력 옵션을 한눈에 보도록 창을 정리하고, 프로젝트마다 마지막 내보내기 설정을 기억합니다. Rust GPU의 처리 프레임과 마지막 MP4 마무리 단계를 구분해 표시하며, 저장 공간 정보는 별도 팝업에서 확인할 수 있습니다. 두 엔진의 차이를 설명하는 도움말도 추가했습니다.
- **파일 이름 중복 방지:** 내보내기 기본 이름으로 프로젝트 제목을 사용합니다. 같은 이름이 있으면 `(2)`, `(3)`을 붙여 기존 파일을 보호하고, 사용자가 직접 중복 이름을 입력하면 경고합니다. TTML 단어별 타이밍을 가진 가사도 LRC·SRT로 내보낼 수 있도록 개선했습니다.
- **미리보기 품질 선택:** **절전·균형·최상** 세 단계로 품질 설정을 정리했습니다. 균형이 기본값이며, 기존 저장 설정을 새 정책에 맞게 이전합니다. 이 설정은 편집 중 미리보기에 적용되며 최종 영상 출력 해상도를 바꾸지 않습니다.
- **곡별 가사 미리보기:** 곡 정보/설정창에서 창 크기에 맞춰 표시할 이전·다음 가사 줄 수를 조절하고, TTML의 단어별 진행과 겹쳐 부르는 가사를 더 자연스럽게 보여줍니다. KRC 단어 시간이 겹치는 경우도 처리하며, 실제 시간 순서가 잘못된 데이터는 구분해 알립니다.
- **가사 번역 작업 개선:** 번역할 부분뿐 아니라 노래 전체의 흐름과 반복 구절을 참고하도록 개선했습니다. 로컬 모델 검색·설치·선택·삭제 과정을 정리하고, 연결 실패 원인을 더 자세히 표시합니다. 일부 가사만 번역에 성공해도 완료된 결과를 유지하고 실패한 부분을 다시 시도할 수 있습니다.
- **설정과 편집창 정리:** 프로그램 설정과 단축키 목록에 검색 기능을 추가하고, 여러 설정창의 입력 항목과 버튼 배치를 통일했습니다. 가사 번역창과 키프레임 편집창도 작업 순서가 더 잘 보이도록 정리했습니다.
- **미리보기 및 렌더링 개선:** 반복되는 화면 요소의 처리와 긴 플레이리스트의 키프레임 조회를 효율화했습니다. 화면을 되감거나 빈 GPU 장면으로 전환했을 때 이전 화면이 남을 수 있던 문제를 수정했습니다. 실제 재생 성능은 프로젝트와 PC 환경에 따라 달라집니다.
- **가사·시각 효과 및 내보내기 오류 수정:** 비주얼라이저의 위치·반전이 편집 화면과 최종 영상에서 다르게 나타나는 문제를 줄이고, 가사 글로우와 경계 블러를 함께 사용할 때 미리보기가 종료될 수 있던 오류를 수정했습니다. 내보내기 준비 단계의 진행 상태가 되돌아가 보이던 현상과 일부 잘못된 영상 파일 정보 처리도 보완했습니다.

## 설치 및 참고

- **Windows 64비트용**입니다. 정식 릴리즈에 첨부되는 `Music Motion Studio-1.4.1.0-setup.exe`를 실행하거나, 공개된 정식 업데이트가 감지되면 앱의 자동 업데이트를 이용하세요. 설치본 사용자는 Python이나 Rust를 별도로 설치할 필요가 없습니다.
- **Rust GPU** 엔진은 지원되는 NVIDIA GPU와 드라이버 환경에서 사용할 수 있으며 H.264 MP4 출력에 맞춰져 있습니다. 지원되지 않거나 준비 단계에서 실패하면 FFmpeg 경로를 사용할 수 있습니다. 실제 내보내기 속도는 PC와 프로젝트 구성에 따라 달라집니다.
- **FFmpeg는 설치 파일에 포함되지 않습니다.** FFmpeg 엔진의 영상·오디오 내보내기와 AutoMix 분석·미리듣기 등에 필요하며, **도구 → 설정 → FFmpeg**에서 설치하거나 경로를 지정할 수 있습니다.
- **AutoMix는 베타 기능**입니다. 전환 결과를 영상으로 내보내기 전에 미리 들어 보세요. 중요한 기존 프로젝트는 업데이트 전에 사본을 보관하는 것을 권장합니다.
