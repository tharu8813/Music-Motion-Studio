# Playlist Canvas 1.3.1.4

내보내기 화면 생성 속도를 개선하고, AutoMix 음량 분석과 프로젝트 편집 상태 처리를 보완했습니다.

## 내보내기

- 독립적인 Canvas 레이어를 별도 렌더 작업자에서 동시에 생성해 FFmpeg가 다음 화면을 기다리는 시간을 줄였습니다. 지원 구성에서는 자동으로 적용하며, 같은 Z값이 겹치거나 임시 변환이 남은 장면 등은 기존 경로를 유지합니다.
- 최종 영상에 포함되지 않는 중복 캡처와 불필요한 픽셀 변환을 줄였습니다. 출력 해상도·FPS·인코딩 품질을 낮추는 방식의 개선은 아닙니다.
- 가사 블러의 임시 메모리를 줄이고 자주 사용하는 가사 이미지의 캐시 재사용을 개선했습니다.
- 준비 중 취소, 렌더 작업자 오류와 인코더 실패 시 프로세스·전송 스레드를 정리하는 처리를 보완했습니다.
- 특정 1080p·60fps·20초 표본에서는 기존 경로 49~54초, 빌드된 병렬 작업자 사용 시 36~44초를 관측했습니다. 효과는 장비와 프로젝트 구성에 따라 다릅니다.

## 오디오와 프로젝트 안정성

- AutoMix 음량 분석에서 긴 FFmpeg 로그의 앞부분이 누락돼 정규화 결과가 미리보기와 달라질 수 있는 문제를 수정했습니다. 오류 진단 로그의 크기 제한은 유지합니다.
- 프로젝트 복원 중 변경 기록과 자동 저장이 중간 상태를 저장하지 않도록 편집 상태 처리를 정리했습니다.
- 저장 중 새로 편집한 내용이 저장 완료 처리에 묻히지 않도록 보완하고, 자동 저장을 마무리하는 동안 UI 이벤트 처리를 유지합니다.
- 미리보기 프레임 캐시와 FFmpeg 실행 경로를 정리하고, 소스 설정 검증과 오류 처리를 보완했습니다.

## 설치 안내

- 기존 프로그램을 종료한 뒤 `Playlist.Canvas-1.3.1.4-setup.exe`를 실행하거나 앱의 자동 업데이트를 사용하세요.
- 병렬 렌더링은 추가 메모리를 사용합니다. 모든 프로젝트에서 RAM 사용량을 2GB 이하로 제한하는 기능은 아닙니다.
- Windows용 FFmpeg는 기존과 같이 앱 설정에서 검증된 배포본을 내려받아 사용합니다.
