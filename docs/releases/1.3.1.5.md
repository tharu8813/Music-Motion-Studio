# Playlist Canvas 1.3.1.5

가사를 온라인에서 찾아 원하는 줄만 연결하고, 긴 자막을 단어 단위로 줄바꿈할 수 있습니다. 가사 편집과 작은 창에서의 작업 편의성을 개선하고 도움말을 최신 화면에 맞췄습니다.

## 새로운 기능
- **온라인 가사 검색:** KuGou·AMLL TTML DB·LRCLIB에서 가사를 찾아 미리 확인하고 저장하거나 곡에 연결할 수 있습니다. 플레이리스트에서 곡을 고르거나 제목·아티스트를 직접 입력하세요.
- **원하는 가사만 적용:** 검색한 가사에서 사용할 행을 선택하고, 기존 가사와 비교한 뒤 교체할 수 있습니다. 파일로 저장하면 제공된 원본이 유지됩니다.
- **단어 단위 자동 줄바꿈:** 가사/자막 속성에서 글꼴 크기 자동 감소와 자동 줄바꿈을 각각 설정할 수 있습니다. 줄바꿈 기준은 요소 너비 또는 직접 지정한 너비로 선택합니다. 자동으로 나뉜 줄은 가깝게 표시하고, 원래 가사의 줄 간격은 유지합니다.
- **요소 꾸미기:** 좌우·상하 뒤집기, 프레임 너비·색상·여백 설정과 새로운 반복 모션을 추가했습니다.

## 개선 사항
- 가사 검색의 입력 방식을 라디오 버튼으로 구분했습니다. 곡 정보를 수정하면 직접 입력으로 전환하며, 결과 표에서 가사 타입을 쉽게 확인할 수 있습니다.
- 다음 가사가 각 큐 전환 직전부터 화면 밖에서 들어오고, 전환 후에도 같은 위치에서 이어지도록 개선했습니다.
- 작은 창에서 속성 범주를 선택하고 대화상자와 내보내기 설정을 사용하는 과정을 개선했습니다.
- 가사 표시 설정, 누락된 음악 파일과 사용할 곡이 없는 상태를 경고로 안내합니다.
- 한국어·영어 도움말에 새 기능 설명을 추가하고 화면 이미지를 갱신했습니다.

## 오류 수정
- 첫 가사 시작 전의 표시, 겹치는 TTML 가사와 간주 뒤 가사 전환을 보완했습니다.
- TTML 줄을 삭제한 뒤 선택이 남아 다른 줄을 연속해서 삭제할 수 있던 문제를 수정했습니다. 편집기를 닫아도 상위 곡 설정 창은 유지됩니다.
- 프로젝트 상태 복원 후 플레이리스트의 곡 행이 보이지 않거나 작은 미리보기에서 재생바가 잘리는 문제를 수정했습니다.

## 설치 및 참고
- Windows용 설치 파일을 실행하거나 앱의 자동 업데이트를 이용하세요.
- 영상·오디오 내보내기와 AutoMix에는 FFmpeg가 필요합니다. 도구 → 설정 → FFmpeg에서 설치할 수 있습니다.
- 온라인 가사 검색에는 인터넷 연결이 필요하며, 제공자에 따라 결과와 지원 형식이 다릅니다. 시간 정보 없는 가사는 복사·저장만 가능합니다.
- TTML의 단어·음절 강조는 원본 파일에 시간이 있는 경우에만 사용합니다. TTML 줄 삭제 모드는 남은 줄의 시간 정보를 보존하며 원본 파일을 수정하지 않습니다.
- 기존 프로젝트는 먼저 별도 사본으로 저장해 두는 것을 권장합니다.
