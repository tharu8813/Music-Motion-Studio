# 가사 검색 및 가져오기

진입점은 **도구 → 가사 검색 및 가져오기…**와 **곡 설정 → 가사 → 가사 찾아보기…**입니다.
제목은 필수이며 아티스트, 앨범, 길이(초), 제공자를 지정합니다.
LiriQo가 제목·아티스트·길이로 음원을 찾고 제공자별 가사를 한 번에 반환합니다.
앨범은 반환된 메타데이터의 부분 일치 필터입니다. 검색 국가 선택은 지원하지 않습니다.
제목과 아티스트가 있는 현재 플레이리스트 곡을 선택하면 입력값과 연결 대상이 채워집니다.
검색과 가사 불러오기는 백그라운드에서 실행하며 취소하거나 창을 닫을 수 있습니다.

결과의 제목·아티스트·앨범·길이·제공자를 확인하고 행을 선택하면 가사를 미리 봅니다.\n검색 결과 내 필터, 가사 텍스트 복사, Ctrl+F(곡 제목), Ctrl+Shift+F(결과 필터)를 지원합니다.
검색 결과는 LiriQo가 찾은 한 음원의 제공자별 가사 버전입니다. 오류가 발생하면
다른 결과/제공자를 선택하거나 행을 두 번 클릭해 다시 불러올 수 있습니다.

- **로컬 다운로드**: 선택한 위치에 TTML/LRC를 저장합니다. 구조화된 단어 시간은 TTML로 변환합니다.
  시간 정보 없는 결과는 TXT 다운로드만 지원합니다.
- **플레이리스트에 추가**: 대상 곡에 시간 정보가 있는 가사를 연결합니다.
  기존 가사가 있으면 비교창을 엽니다. 가사는 프로젝트에 내장되어 저장됩니다.
  곡 설정에서 연 창은 임시 편집 상태에 연결하므로 상위 곡 설정의 적용/취소를 따릅니다.

TTML과 LiriQo의 단어·음절 시간은 유지합니다. LRCLib (estimated word sync)는 LiriQo가
비례 배분한 추정 단어 시간이며, LRCLib의 줄 단위 결과도 별도로 선택할 수 있습니다.
검색 도구는 음악 파일이나 오디오 태그를 수정하지 않습니다.

실시간 가사의 사용 여부, 강조할 줄, 색상과 단어 강조 보정은 **가사/자막 요소 →
속성 → 실시간 가사**에서 설정하며 해당 요소에 표시되는 모든 곡에 공통 적용합니다.
강조할 줄은 비워 두면 전체 줄이며, `1, 3`처럼 입력하면 해당 위치의 줄만 강조합니다.
곡 설정에는 가사 연결과 곡별 타이밍 보정만 두며, 검색으로 TTML을 연결해도
요소의 표시 설정을 자동으로 바꾸지 않습니다.

## 제공자 연동

[LiriQo](https://github.com/AlFarrizi-Studio/LiriQo)의 공개 API
`https://api.liriqo-alfarrizi.my.id/v1/lyrics`를 사용합니다. 별도 API 키나
추가 Python 패키지 설치는 필요하지 않습니다.

제목, 아티스트, 길이를 한 번 전송하면 LiriQo가 음원을 확인하고 Apple Music,
Unison, QQ Music, KuGou, LRCLib, YouTube Music, NetEase 가사를 반환합니다.
제공자와 시간 정보 필터는 이 응답에 적용하며, 앨범은 반환된 메타데이터의
부분 일치 필터입니다. 검색 국가 지정은 API에서 지원하지 않습니다.
동일 제목의 여러 음원을 나열하는 카탈로그 검색이 아니므로 원하는 음원이
아니면 제목과 아티스트를 구체적으로 입력해 다시 검색하세요.

결과는 음절 → 단어 → 줄 → 일반 텍스트 순으로 표시합니다. 선택한 결과에
포함된 가사를 미리보기·다운로드·연결에 사용하므로 추가 조회에서 다른 음원으로
바뀌지 않습니다. 원본 TTML/LRC가 있으면 보존하고, 단어별 구조화 시간만 있는
결과는 밀리초를 초로 변환해 TTML로 저장합니다. 줄 시간만 있는 결과는 단어
시간을 생성하지 않습니다. 일반 텍스트는 TXT 다운로드만 가능합니다.

요청은 백그라운드에서 실행하며 30초 네트워크 제한, 8 MB 응답 제한,
취소 확인, 호스트별 1초 요청 간격을 적용합니다. 응답은 10분 캐시하며
창 사이에 공유하고 최대 64개/32 MB로 제한합니다. HTTP 429 및 일시적인
서버 오류는 자동 재시도하지 않습니다. `Retry-After`를 존중하고 대기 중
취소할 수 있습니다. API 또는 상위 제공자의 장애로 결과가 없을 수 있습니다.

가사는 기존 파서와 프로젝트 검증을 통과한 뒤에만 프로젝트에 연결됩니다.
