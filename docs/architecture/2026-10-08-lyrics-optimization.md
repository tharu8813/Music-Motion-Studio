# 자막·가사 응답성과 사용 흐름 개선 — 2026-10-08

기존 작업 트리의 가사·노래방·타이밍 정렬 기능을 보존하고, 렌더링과 편집 중 반복 작업을 줄였다. 새 의존성을 추가하지 않았다.

## 수정한 경로

| 경로 | 원인 | 수정 |
| --- | --- | --- |
| 색상 전환·글로우·이전/다음 줄 흐림 | 색상이 바뀔 때 같은 글자의 Gaussian 흐림을 다시 계산하고, 투명 영역까지 색상 배열을 생성 | 색상과 분리한 흐림 마스크 재사용. 알파·글꼴·흐림 반경·배율·정렬·크기는 캐시 키에 유지. 실제 글자와 Gaussian 커널 범위 안에서만 계산·착색한다. |
| 렌더링 캐시 | 96개를 넘으면 모든 글자 이미지를 삭제 | 오래된 항목부터 하나씩 제거. 추가 마스크 캐시는 소스별 48개·16MiB 이하로 제한하고 글꼴 설정 변경 시 비운다. |
| 인트로 상태 | 사용하지 않아도 매 프레임 전체 가사를 필터링 | 비활성 상태는 즉시 반환. 활성 상태는 첫 번째 유효 가사를 찾으면 탐색을 종료한다. |
| 고급 전환 설정 | 연속 값 변경마다 즉시 미리보기 렌더링. 많은 가사를 표시하면 큰 이미지를 만든 뒤 축소 | 이벤트 루프에서 변경을 합쳐 한 번 갱신하고 표시 영역 크기로 캡처한다. 설정값 자체는 즉시 갱신한다. |
| LRC 타이밍 기록 | 재생 위치 알림마다 모든 시간 정렬 및 전체 행 스타일 변경. 시간 수정마다 모든 셀 재생성 | 시간 편집 때 정렬하고 재생 중에는 이진 탐색. 표시가 바뀐 행만 꾸미고 기존 셀을 재사용한다. 같은 가사 안에서는 스크롤을 반복 이동하지 않는다. |

## 사용 흐름 확인과 개선

- **스타일 비교:** 고급 설정에 일시정지/계속 재생을 추가했다. 정지 상태에서 설정을 바꾸면 같은 미리보기 시간으로 비교할 수 있다. 다시 재생은 시작 위치부터 재생한다. 닫으면 재생·예약 갱신 타이머를 중단한다.
- **가사 읽기:** 타이밍 편집기의 미리보기 모드에서는 비활성 편집 도구를 숨겨 목록 공간을 확보한다. 체크를 해제하면 도구를 복원한다. 한국어 1200×760 화면에서 이중 언어 가사 표시 공간이 늘어난 것을 확인했다.
- **파일 불러오기:** UTF-8/BOM과 BOM이 있는 UTF-16을 지원한다. 잘못된 인코딩은 처리되지 않은 예외 대신 다시 저장할 형식을 안내한다. 시간 정보를 인식하지 못한 파일은 곡 설정의 기존 가사를 덮어쓰지 않는다.
- **접근성:** 고급 설정 입력에 레이블 기반 접근성 이름을 제공하고 미리보기 가사 수에도 이름을 추가했다. 정지/재개는 키보드로 조작 가능한 기본 Qt 버튼을 사용한다.

## 재현 측정

동일한 로컬 Qt offscreen 조건에서 2,000개 이중 언어 가사를 사용했다. 렌더링은 효과별 90프레임, 설정 편집은 가사 수·방향 변경과 연속 값 변경, 타이밍 편집은 40번의 재생 위치 갱신과 단일 시간 수정을 측정했다. 시뮬레이션한 UI 경로의 시간이며 전체 프로그램의 배속을 뜻하지 않는다.

| 항목 | 수정 전 | 수정 후 |
| --- | ---: | ---: |
| 연속 설정 변경·최종 미리보기 갱신 | 73.36ms / 23회 렌더링 | 12.43ms / 1회 렌더링 |
| 타이밍 재생 위치 갱신 중앙값 | 20.40ms | 0.004ms |
| 타이밍 재생 위치 갱신 P95 | 20.88ms | 0.009ms |
| 시간 한 개 수정·표 갱신 | 45.92ms | 8.28ms |
| 글로우 90프레임의 Gaussian 호출 | 635회 | 452회 |
| Rise / Glow / Karaoke 프레임 시간 P95 | 42.61 / 72.06 / 43.35ms | 29.77 / 68.88 / 43.54ms |

세 효과 모두 **90개 전체 프레임의 누적 SHA-256이 변경 전후 일치**한다. 시간·색·투명도·글자 배치의 출력을 유지했다. 정밀한 흐림 반경을 거칠게 반올림하는 최적화는 적용하지 않았다.

측정 시간은 실행 부하에 따라 달라진다. 특히 무거운 글로우 전환은 이 조건에서도 30fps의 33.3ms를 넘는 프레임이 남아 있으므로, 모든 효과에서 프레임 멈춤이 완전히 사라졌다고 볼 수 없다. GPU 렌더링이나 실제 사용자·스크린리더 평가는 이번 확인에 포함하지 않았다.
