# 키프레임 편집 편의 기능과 프로그램 도움말 점검

2026-11-03. [직전 UI 정리](2026-11-03-motion-editor-ui.md)에 화면 탐색·단축키·슬라이더·첫 실행 안내를 추가하고, 프로그램 도움말을 현재 기능과 대조했다.

## 편집 편의

- 미리보기 휠로 커서 위치를 기준으로 확대·축소한다. 배율은 5~800%로 제한하며 맞춤·100%로 복원한다. 확대 시 기존 렌더러의 이미지 갱신을 요청하고 기존 2배 캡처 상한을 유지한다. 좌표와 모션 계산은 바꾸지 않는다.
- 빈 곳 드래그, 가운데 버튼 드래그, Space를 누른 채 왼쪽 드래그로 화면을 이동한다. Space만 누르고 떼면 재생·일시 정지를 전환한다. 화면 이동은 Source·키프레임·Undo·자동 저장을 변경하지 않고 재생 중에도 유지된다. 가이드는 원래 프로젝트 좌표를 따른다.
- 현재 값 패널에는 공통 속성창 스타일의 슬라이더를 두고 숫자 입력을 오른쪽에 배치했다. 큰 수치를 직접 입력하면 슬라이더 범위가 넓어지고 값은 잘리지 않는다. 위치·회전의 범위는 0을 중심으로 확장한다. 한 번의 드래그는 Undo 한 번이다.
- 선택한 속성의 현재 값만 기본 상대값으로 복원하는 버튼과 Ctrl+Backspace를 제공한다. 다른 시점과 다른 속성은 보존한다.
- 효과 밖 미리보기는 이제 길이를 직접 입력하지 않는다. 항상 효과 길이의 **50%**이며, 곡 시작 뒤 / 곡 끝 앞에만 붙는다. 0.1~10초의 효과에서 비율을 확인했다. 회색 구간의 편집 잠금은 유지한다.
- 첫 실행 시 공통 `GuideDialog`를 사용하는 그림 안내 3페이지를 표시한다. 기존 첫 실행 설정 방식으로 사용자별 한 번만 열고, 상단 안내 아이콘으로 다시 볼 수 있다. 건너뛰기를 지원한다. 안내는 프로젝트를 변경하지 않는다.
- 실제 표시된 모니터의 크기에 맞춰 공통 `AdaptiveDialog`로 창을 맞춘다. 높은 DPI·낮은 화면에서는 트랙 목록을 스크롤하며 선택한 트랙을 자동으로 보이게 한다. 미리보기와 적용 버튼은 접근 가능한 상태를 유지한다.

## 단축키

| 키 | 동작 |
| --- | --- |
| Space / L | 재생·일시 정지 / 반복 |
| ←/→, Shift+←/→ | 0.01초 / 0.1초 탐색 |
| Home/End, Ctrl+Home/End | 미리보기 범위 / 효과 범위 처음·끝 |
| Ctrl+←/→ | 선택 트랙의 이전·다음 점 |
| 1~5, ↑/↓ | 속성 트랙 선택 |
| K, Delete/Backspace | 점 추가 / 삭제(끝점 보호) |
| E, Ctrl+Backspace | 트랙 켜기·끄기 / 현재 값 초기화 |
| B / P | 구간 곡선 / 프리셋 |
| Ctrl+Z, Ctrl+Shift+Z 또는 Ctrl+Y | 로컬 Undo / Redo |
| G / O | 가이드 / 원본 비교 |
| F 또는 Ctrl+0, 0 또는 Ctrl+1 | 맞춤 / 100% |
| + / − | 확대 / 축소 |
| F1 / Shift+F1 | 편집기 사용 도움말 / 단축키 목록 |

텍스트·숫자·목록에서는 일반 입력을 우선한다. 슬라이더 방향키는 값 조절을 유지한다. 효과 밖·잠금·꺼진 트랙의 편집 제한은 단축키에도 적용된다. 드래그 도중에는 시간 이동·모달 창 열기를 막아 한 번의 편집 트랜잭션을 보호한다. 화면 이동 모드에서 Esc는 이동 모드만 종료하고, 다시 Esc를 누르면 편집기를 취소한다. 닫을 때 응용 프로그램 이벤트 필터와 입력 상태를 해제한다.

## 도움말 점검

6개 탭, 한국어·영어 각 **70개 주제**를 기준으로 주요 메뉴와 실제 편집 경로를 대조했다. 이번에 확인한 누락·불일치는 다음과 같다.

| 영역 | 대조 및 조치 |
| --- | --- |
| 요소·레이어·캔버스·프로젝트 콘텐츠 | 기존 추가·그룹·잠금·미리보기·파일 연결 설명 확인 |
| 속성창 | 개편 전 8개 탭 설명을 현재 콘텐츠·배치 및 변형·디자인·애니메이션·고급으로 수정. 가사 줄 배치·줄별 스타일의 이전 경로도 수정 |
| 애니메이션 | 사용자 지정 시작/끝 편집, 독립 속성·구간 베지어·프리셋·활성화, 상대 값과 저장/취소, 슬라이더·화면 이동·첫 안내 설명 추가 |
| 이전 키프레임 | 데이터 보존, 호환 보기, 새 모션과의 중복 재생 방지와 적용 시 확인 정책 추가 |
| 배경 | 누락된 앰비언트 블러·흐름·베이스 반응 확대·배경 전환을 별도 주제로 추가 |
| 영상·출력 | 영상 효과 출력의 없음·페이드·사용자 지정 지원과 다른 프리셋/반복 모션 제한, 편집기의 영상 정지 화면 제한 추가 |
| 가사·번역·곡 설정·AutoMix | 기존 검색·연결·단어 시간·줄 스타일·번역 초안/로컬 모델, 곡 정보/분석/오디오, 전환 편집·고정·듣기·프리셋 주제와 접근 경로 대조 |
| 설정·프로젝트·FFmpeg·업데이트 | 기존 파일/복구·설치/내보내기·유지 관리 설명 확인. 설정의 계정 탭과 로그인 보존/로그아웃 설명 보완 |
| 단축키 | 전체 단축키 안내에 사용자 지정 편집기 그룹 추가. 창 안에서는 F1/Shift+F1로 해당 도움말을 바로 열도록 연결 |

추가한 네 주제는 `custom_motion`, `motion_shortcuts`, `legacy_keyframes`, `background_effects`다. 검색 태그, 관련 링크, 베지어·앰비언트·슬라이더 검색을 보완했다. 한국어·영어의 현재 속성창 이미지를 갱신하고 실제 프로젝트 기반 모션 편집기 이미지를 추가했다. 도움말 창도 공통 화면 맞춤 동작을 사용한다. 이미지 생성은 `tools/capture_motion_help_images.py`로 재현하며 사용자 설정과 데이터를 격리한다.

## 검증

관련 5개 모듈 **63개 테스트가 모두 통과**했다. 별도의 영어 150% 배율 GUI **27개도 모두 통과**했다. 중복 실행을 합산하지 않았으며 전체 저장소 재실행 결과는 아니다. 작은 보조 모니터에서 높이가 넘치던 문제는 실제 표시 모니터에 맞춘 뒤 재검증했다.

검증에는 실제 Qt 휠·빈 곳/가운데/Space 드래그, 커서 위치 보존과 배율 상한, 재생과 손 도구 충돌, Esc, 점 추가/삭제/선택·Undo, 입력창 우선 처리, 슬라이더 동기화·큰 값·단일 Undo, 첫 실행 한 번/다시 열기, 50% 구간, 실제 FFmpeg 출력 회귀가 포함된다. 도움말은 양 언어 주제 일치·검색·링크·F1 대상·이미지 자원, 공통 스타일 자원을 검사했다. `compileall`과 `git diff --check`도 통과했다.

주요 변경 파일은 `custom_motion_dialog.py`, `motion_canvas.py`, 새 `motion_editor_shortcuts.py`·`motion_editor_guide.py`, `help_content.py`, `help_dialog.py`, `shortcuts_dialog.py`, 두 도움말 이미지 묶음 및 관련 테스트다. 기존 영상 정지 화면·예시 음악 반응·출력 제한은 도움말에 명시한 대로 유지한다.
