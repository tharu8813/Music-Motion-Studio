# 사용자 지정 모션의 속성별 트랙과 구간 곡선 편집

> 최신 간단/고급 모드·자세 연결·영상 동기화·검증 범위는 [편집기 완성도 개선 기록](2026-11-03-motion-editor-completion.md)을 따른다.

> 현재 UI와 미리보기 방향은 [후속 UI 정리·트랙 활성화 안내](2026-11-03-motion-editor-ui.md)를 따른다. 아래 양쪽 여유 구간 설명은 이 문서를 작성한 단계의 기록이다.

2026-11-03 후속 개선. [1차 시각적 편집기](2026-11-03-custom-motion-editor.md)의 전체 자세 키프레임 한 줄을 X·Y·크기·회전·투명도 다섯 트랙으로 변경했다.

## 편집 흐름

하단에 X, Y, 크기, 회전, 투명도를 위에서 아래로 배치한다. 각 행의 왼쪽에는 이름과 추가·삭제·이전 선택·다음 선택 버튼, 중앙에는 공통 시간축의 키프레임 재생 바, 오른쪽에는 곡선 편집과 곡선 프리셋을 둔다. X의 점을 추가·삭제·이동해도 다른 속성의 점과 보간은 변하지 않는다. Canvas에서 직접 이동하면 X/Y, 크기 핸들을 조작하면 크기, 회전 핸들을 조작하면 회전 트랙만 갱신한다.

키프레임 사이를 누르면 해당 시간으로 이동하고 그 행의 두 인접 점 사이 구간을 강조한다. 구간 내부에서도 곡선을 편집할 수 있으며, 곡선 편집 때문에 재생 헤드 위치에 불필요한 키프레임을 만들지 않는다. 정확히 한 점에 있으면 다음 구간을 선택하고, 마지막 점에서는 직전 구간을 사용한다.

곡선 편집에는 구간의 실제 시작/끝 시간과 값이 표시된다. 크기와 투명도는 퍼센트 값이다. 적용하면 해당 구간만 베지어로 저장하고 프리셋을 `사용자 지정...`으로 표시한다. 취소하면 기존 곡선과 프리셋을 유지한다. 같은 모양의 곡선을 직접 작성했더라도 사용자 지정이라는 선택 상태를 저장한다.

## 프리셋 팝업

메뉴 형태의 팔레트에서 그래프 아이콘과 아래의 이름을 함께 표시한다. 유지, 선형, 서서히 시작, 서서히 종료, 부드럽게, 반동, 사용자 지정 항목을 제공한다. 사용자 지정을 누르면 베지어 편집기를 연다. 프리셋을 고르거나 곡선 창을 편집하는 동안 구간이 바뀌지 않도록 재생을 잠시 정지하고 닫은 뒤 이어간다.

## 효과 전후 재생

`앞뒤 미리보기`에서 효과 앞뒤의 재생 여유 시간을 각각 0.05~5초로 설정한다. 기본은 앞뒤 각 0.5초다. 시작 버튼, 스크럽, 일반 재생과 반복 재생은 이 여유 구간까지 포함한다. 효과 자체의 지속 시간과 키프레임의 정규화된 시간은 바뀌지 않는다.

효과 전후를 회색으로 구분한다. 재생 헤드가 효과 밖에 있으면 `효과 밖 미리보기 · 이 구간은 편집할 수 없습니다.`를 표시하고 수치·지속 시간·Canvas 핸들·키프레임 추가/삭제/이동·곡선 편집/프리셋을 비활성화한다. 이전/다음 점 선택으로 편집 구간에 돌아올 수 있다. 여유 구간에서는 선택 모션의 시작 또는 마지막 자세를 유지한다. 전체 플레이리스트나 이웃 곡의 오디오를 새로 재생하지 않는다.

## 데이터와 출력

기존 `CustomMotion.points`를 그대로 읽는다. 새 `curves`에는 속성 이름, 독립적인 키프레임 목록, 직접 작성한 구간 표시를 저장한다. 아직 편집하지 않은 속성은 기존 자세에서 유도한 곡선을 사용하므로 기존 모션을 다시 샘플링하거나 보간을 바꾸지 않는다. 변경한 속성만 별도 곡선을 저장한다.

Canvas와 FFmpeg 모두 기존 `motion_curves`/`CustomMotion.at` 경로에서 이 독립 곡선을 평가한다. 시작·끝 분리, 상대 이동과 배율, 적용/취소, 프로젝트 Undo, AutoMix/크로스페이드의 시간 계획은 유지한다. 편집기의 여유 시간은 미리보기 설정이며 프로젝트의 효과 길이나 최종 출력 시간을 늘리지 않는다.

## 검증

이번 변경 후 Windows 네이티브 Qt와 실제 FFmpeg로 관련 8개 모듈 **97개 테스트를 모두 통과**했다. 별도 영어 150% DPI 실행에서도 GUI **17개를 모두 통과**했다. 두 실행의 중복 테스트 수는 합산하지 않았다. 전체 저장소 테스트를 이번 후속 변경 후 새로 모두 실행한 것은 아니다.

- X/Y 독립 추가·삭제·선택·이동과 로컬 Undo, Canvas 핸들·수치 동기화
- 점 사이 구간 클릭, 프리셋 팝업의 실제 버튼·아이콘·이름, 구간 하나만 변경
- 베지어 적용/취소와 사용자 지정 표시, 다른 속성 보간 보존
- 곡 시작/끝 모두에서 효과 전후 읽기 전용 상태와 경계 자세
- 여유 시간까지 일반/반복 재생, 정지, 팝업 동안 구간 유지
- 속성별 시간·베지어·사용자 지정 표시의 JSON 왕복 및 잘못된 새 데이터 복구
- 프로젝트 파일 저장/복원, 텍스트·이미지·커버 최종 MP4 비교
- 다섯 속성이 서로 다른 시각에 변화하는 실제 MP4의 위치·알파 비교
- 기존 키프레임 렌더링, GPU 비교, 출력 시간표·계획, 프로젝트 서비스 회귀

`compileall`과 `git diff --check`도 통과했다. [실행 결과 JSON](benchmarks/2026-11-03-motion-property-lanes.json)에 모듈별 결과를 보존한다. 실제 화면은 저장소의 `work/motion-lanes-ko.png`, `work/motion-lanes-en-150.png`, `work/motion-curve-presets-ko.png`에서 확인할 수 있다.

수정 대상은 `app/animation/custom_motion.py`, `app/dialogs/custom_motion_dialog.py`, `app/dialogs/motion_timeline.py`, 새 `app/dialogs/motion_curve_presets.py`, 두 사용자 지정 모션 테스트 모듈과 이 문서다. 영상 정지 화면과 예시 음악 반응 등 1차 편집기의 미리보기 제한은 유지한다.
