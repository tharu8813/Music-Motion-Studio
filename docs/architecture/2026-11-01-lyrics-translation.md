# 가사 번역

## 사용 흐름

1. **곡 정보/설정 → 가사 설정 → 가사 번역…**을 연다. 한 창의 위쪽에서 원문·번역 언어, 번역 방식, 현재 서비스·모델과 준비 상태를 확인하고, 아래쪽 표에서 결과를 검토·편집한다.
2. 이미 준비한 서비스라면 **번역 시작**을 바로 누른다. 처음이라면 **서비스 및 모델 설정…**에서 선택한 방식에 맞는 인증·모델을 준비한다. ChatGPT 로그인은 **OpenAI 계정 관리…**를 사용한다. API 서비스는 **모델 불러오기**나 **연결 테스트**로 모델을 조회하고, 모델 ID를 직접 입력하려면 **고급 설정…**을 사용한다.
3. 로컬 LLM은 별도 **로컬 LLM 관리자…**에서 실행 구성요소와 모델을 준비한다. 비LLM은 서비스 설정에서 현재 언어 방향의 모델을 자동 설치하거나 `.argosmodel`을 가져온다. 설정을 닫아도 언어와 선택한 서비스·모델은 유지한다.
4. **번역 시작**을 누르면 같은 창에서 진행률·취소와 실시간 결과를 함께 확인한다. 화면 아래 원문·번역 표에서 바로 비교하며, 번역이 끝나면 창 이동 없이 편집·적용한다. 서비스 설정 창을 닫아도 번역은 계속된다. **진행 행 따라가기**는 기본으로 꺼져 있으며 원하는 때만 켠다.
5. 번역문 셀을 두 번 클릭해 편집한다. Enter는 줄바꿈, Ctrl+Enter는 편집 완료다. **모든 행 / 번역되지 않은 행 / 실패·미완료 행 / 수정한 행** 필터를 사용한다. **선택한 행 재번역**은 표에서 강조한 행을, **실패한 행 재번역**은 실패·미완료 행을 다시 요청한다. 적용 체크 상자와 재번역할 행 선택은 별개다. 재번역할 때는 해당 행의 직접 수정 내용도 교체된다고 확인한다.
6. **초안 저장**(Ctrl+S)으로 초안을 보존한다. 창을 닫아도 번역문·선택 상태·수정 및 실패 상태를 저장하므로 같은 곡과 같은 원문에서 번역 창을 다시 열어 이어서 작업한다. 초안은 기기 설정에 저장하고 프로젝트에는 넣지 않는다. 적용 전에는 프로젝트 가사를 변경하지 않는다.
7. **선택한 N줄 적용**으로 체크한 행만 곡 설정에 반영하고 곡 설정의 **적용** 뒤 프로젝트를 저장해 확정한다. 번역 창에서 적용해도 복구 초안은 지우지 않으므로, 곡 정보 창에서 취소했다면 같은 곡의 번역 창을 다시 열어 복원한다. 빈 번역문으로 기존 번역을 삭제하는 경우 별도 확인을 거친다. **초안 삭제…**는 이 곡의 보관본과 현재 편집만 지우며 저장된 곡을 바꾸지 않는다. **번역문 스타일…**은 캔버스 가사 소스의 기존 스타일 창을 연다. 가사 소스가 여러 개면 대상을 선택하며, 가사 소스가 없으면 추가 안내를 표시한다. 스타일은 곡 번역 초안과 별도로 캔버스에 적용한다.

창별 책임·수명과 검증 자료는 [다중 창 번역 작업 공간](2026-11-02-translation-workspace.md)을 참고한다.

## 지원 방식

- 클라우드 LLM: ChatGPT 로그인, OpenAI API, Claude Console API, Gemini API, Grok API.
- 로컬 LLM: Ollama, LM Studio. 서버 주소는 루프백으로 제한하며 클라우드 전용 모델은 설치 목록에서 제외한다.
- 비LLM: Argos의 CTranslate2·SentencePiece 패키지를 앱 안에서 직접 실행하는 로컬 번역만 제공한다. Google Translation·Papago·DeepL·Microsoft Translator·LibreTranslate API 어댑터와 해당 설정은 제거했다. 과거 API 선택 설정이 있으면 로컬 번역 화면으로 안내하며 유료 LLM으로 자동 전환하지 않는다.
- 기존 프로젝트에 저장된 서비스 이름·번역문은 읽기와 편집을 계속 지원한다. 과거 Papago 번역의 표시도 유지한다.

## 로컬 모델

- CTranslate2와 SentencePiece 런타임을 앱에 포함한다. PyTorch·Stanza를 실행에 사용하지 않는다. 모델은 `%LOCALAPPDATA%\PlaylistCanvas\translation-models`에 저장하며 프로젝트 파일에 넣지 않는다.
- 공식 Argos 목록은 사용자가 **이 언어 모델 자동 설치**를 눌렀을 때만 조회한다. 원문→번역 언어 방향을 정확히 대조하며 역방향 모델로 대체하지 않는다. 해당 방향이 없으면 언어 변경 또는 LLM 사용을 안내한다. 설치 후 번역 중에는 네트워크 요청을 보내지 않는다. 지원 언어와 라이선스는 모델별 조건을 따른다.
- 실행 구성요소는 앱에 포함하므로 별도 프로그램 설치가 필요 없다. 언어 방향을 바꿀 때 설치된 일치 모델만 표시하며 없으면 설치 필요 상태를 표시한다. 원문과 번역 언어가 같으면 모델 설치를 요구하지 않는다.
- 메인 창에 비LLM 번역의 정확도 주의를 요약하고, 서비스 설정 창에는 로컬 번역 모델이 LLM AI 모델이 아니며 가사·비유·문맥의 정확도가 크게 떨어질 수 있으므로 클라우드 LLM 또는 로컬 LLM을 권장한다는 경고를 표시한다.
- 지원 패키지에는 `metadata.json`, `sentencepiece.model`, `model/model.bin`, CTranslate2 어휘 파일이 있어야 한다. BPE 전용 패키지는 지원하지 않는다. 모델별 직접 언어 방향을 사용하며 자동 중간 언어 경유는 포함하지 않는다.
- 패키지는 최대 1 GB, 펼친 크기는 최대 2 GB/10,000개 항목으로 제한한다. 경로 이탈·심볼릭 링크·중복 경로를 거절하고 임시 폴더에서 검증한 뒤 설치한다. 모델과 동봉된 라이선스·설명 파일은 유지한다.
- CPU int8로 실행하고 내부 스레드는 최대 4개로 제한한다. 줄바꿈·큐 경계·빈 줄은 유지한다. 한 물리적 줄이 512 모델 토큰을 초과하거나 출력 한도에 도달하면 줄을 나누도록 안내한다. 실행 중 네이티브 추론은 현재 줄이 끝난 뒤 취소를 확인한다.
- BOM·제로폭 구분자만 있는 줄, 기호·숫자만 있는 줄과 이미 목표 언어인 줄은 모델에 보내지 않는다. 혼합 큐에서는 이미 목표 언어인 줄과 기호를 유지한다. 모델의 빔 탐색 결과가 비면 탐욕 디코딩으로 한 번 재시도한다. 그래도 비는 줄은 `IncompleteTranslation`으로 전달하고 다음 줄과 큐를 계속 처리한다.
- 누락이 있는 큐는 표에 **번역 미완료**와 누락된 물리적 줄 번호를 표시하며 적용 선택에서 제외한다. 기존 번역을 지우거나 **번역 불필요**로 간주하지 않는다. 사용자는 번역을 직접 보완한 뒤 선택할 수 있다. 취소하면 기존 미완료 표시와 선택 상태도 복원한다.

## 로컬 LLM 관리자

- 방식 선택·서비스 변경 시 설치 모델을 작업 스레드에서 조회하고 콤보박스에 채운다. Ollama의 `/api/tags`, LM Studio의 `/api/v1/models`를 사용한다. 클라우드 모델과 LM Studio의 임베딩·결정 모델을 제외한다. 사용자가 선택했던 모델이 남아 있으면 복구한다.
- Ollama는 설치 목록·검색·파일 용량·매개변수·양자화·상세 정보·라이선스·다운로드/이어받기·모델 삭제·별칭 생성·메모리 로드/해제를 지원한다. 삭제는 같은 서버를 쓰는 다른 앱에도 반영된다고 안내하고 확인한다. 별칭은 기존 이름을 덮어쓰지 않는다.
- 비교 목록은 Qwen2.5 Coder 3B/7B/14B/32B, Qwen3 Coder 30B, Devstral Small 2 24B, Qwen3.5 4B/9B/27B, Qwen3 4B/8B, Gemma 3 4B를 제공한다. 일반 사용자에게 검색·코딩/JSON·다국어·크기 필터를 제공하고 7B 코딩 모델을 시작점으로 제안한다. Ollama 모델은 공식 라이브러리에 존재하는 태그를 사용하며 LM Studio는 검증된 Hugging Face GGUF 링크가 있는 항목만 비교 목록에 표시한다. 각 모델의 공식 정보 링크와 대략적 다운로드 용량, 장점·제약을 표시한다. 품질 순위나 가사 성능 보장은 하지 않는다. 다른 설치 모델에는 미검증 사실과 언어 지원·JSON 출력·메모리 확인 항목을 표시한다. 임의 모델 이름도 직접 입력해 내려받을 수 있다.
- 처음 사용하는 사용자는 화면 상단의 **실행 준비 → 모델 찾기·설치 → 설치된 모델 선택** 흐름을 따른다. 설치 프로그램과 모델 가중치는 자동으로 배포하지 않으며, 사용자의 명시적 다운로드 요청에만 설치한다. 모델 파일 크기는 필요한 RAM/VRAM과 다르며 코딩 모델이라고 해서 번역의 자연스러움이 보장되지는 않는다.
- 가사 번역 시 로컬 LLM(Ollama/LM Studio)의 **모델 응답 원문**과 **JSON 검증 오류, 누락된 가사 ID, 줄바꿈 불일치, 비정상 종료 사유**를 번역 검토 화면의 **LLM 응답 확인…**에서 별도로 볼 수 있다. API 키와 요청 프롬프트는 이 창에 출력하지 않는다. 원문 출력은 한 요청당 최대 128 KiB로 제한하며 가사 내용이 포함될 수 있으므로 공유 전에 확인하도록 안내한다. 이 진단 데이터는 현재 작업의 메모리에만 보관하며 초안과 프로젝트 파일에 저장하지 않는다.
- 한 묶음의 응답 일부만 올바른 경우 정상 ID의 번역문을 우선 복구하고 불량 ID를 실패 처리한다. 이후 묶음에서 오류가 발생해도 이미 완료된 번역문은 초안과 검토 표에서 유지하며 자동 적용하지 않는다. 실패한 행은 선택을 해제하고 **실패한 행 재번역**으로 재시도한다. 사용자가 직접 취소한 경우의 기존 스냅샷 복원 동작은 유지한다.
- **실행 구성요소 자동 설치·시작**은 Windows x64에서 공식 Ollama GitHub 최신 릴리즈의 독립 실행 ZIP을 내려받는다. API가 제공하는 SHA-256·파일 크기·경로를 검증하고 임시 폴더에서 안전하게 펼친 뒤 앱 전용 폴더에 설치한다. AMD 전용 추가 라이브러리·드라이버 설치는 포함하지 않는다. 다른 플랫폼은 공식 설치 안내를 제공한다.
- 이미 실행 중인 서버는 재사용한다. 사용자가 설치한 Ollama CLI도 시작할 수 있으며, 앱이 직접 시작한 프로세스만 앱 종료 시 종료한다. 루프백에 바인딩하고 클라우드 기능을 끈다. 앱 전용 런타임과 모델은 `%LOCALAPPDATA%\PlaylistCanvas\local-llm`에 보관하며 기존 서버의 모델 저장 경로는 변경하지 않는다.
- LM Studio는 최신 REST API의 설치 모델 조회·다운로드 상태 조회·메모리 로드/해제를 지원한다. 프로그램 설치와 모델 파일 삭제는 공식 앱에서 진행하도록 안내한다. 앱에서 다운로드 조회를 취소해도 LM Studio 서버의 다운로드는 계속될 수 있음을 표시한다. 이전 서버 버전이나 연결 실패는 상태 영역에서 안내한다.
- 조회·설치·다운로드·관리는 UI 스레드를 막지 않는다. 다운로드는 진행률과 취소를 제공하며 창을 닫으면 취소를 요청하고 작업 종료를 기다린다. 개발 검증은 소형 테스트 ZIP과 가짜 API 응답으로 수행하며 수 GB의 실제 실행 구성요소를 자동으로 설치하지 않는다.

## OpenAI 계정

- 별도 로그인 폼에 계정 이메일, 연결 상태, 구독 사용 권한, 로그인 유지 상태를 표시한다. 비밀번호·API 토큰을 표시하거나 직접 입력받지 않고 공식 브라우저 로그인만 사용한다.
- 로그인 시 Windows 사용자 계정의 DPAPI로 암호화해 QSettings에 동기 저장한다. 앱을 다시 실행해도 로그인 정보를 읽고 필요할 때 액세스 토큰을 갱신한다. 회전된 리프레시 토큰도 즉시 함께 저장한다.
- 기존 실행 중 세션도 계정 화면을 열면 암호화 저장으로 이전한다. 번역 창의 API 키 저장 옵션은 ChatGPT 로그인을 삭제하거나 세션 전용으로 바꾸지 않는다.
- **로그아웃**은 원격 해제를 시도하고 로컬 인증 정보를 지운다. 원격 해제를 확인하지 못한 경우 계정 설정에서도 앱 연결을 해제하도록 안내한다. 로그인·연결 확인·로그아웃은 작업 스레드에서 실행한다. 닫기는 취소를 요청한 뒤 작업 종료를 기다린다.
- host ID·PKCE·state·nonce·ID 토큰 서명·issuer·audience·만료·구독 사용 scope 검증을 유지한다. 다른 앱의 로그인 정보를 읽지 않으며 인증 정보는 프로젝트에 저장하지 않는다.

## 결과와 취소

- 실시간 표시는 검토 초안일 뿐 프로젝트를 수정하지 않는다. 요청 실패·취소 시 진행 중 표시한 임시 결과를 되돌리고 이전 검토 상태를 복구한다. 요청 실패 행에는 실패 상태와 원인을 표시하며 적용 체크를 해제한다. 취소는 이전 선택·미완료 상태까지 복구한다. 일부 결과를 자동 적용하지 않는다.
- 원문 언어와 번역 언어 코드를 같게 지정하면 인증·번역 요청을 보내지 않고 빈 결과를 만든다. 지역·문자 변형은 임의로 합치지 않는다.
- LLM에는 큐 전체가 이미 목표 언어이거나 원문과 같은 결과라면 빈 문자열을 반환하도록 지시한다. ID는 반드시 유지한다. 로컬 모델은 확실히 구분할 수 있는 순수 한글·일본어 가나 문장도 목표 언어에 맞으면 비운다. 일반적인 자동 언어 판별기는 포함하지 않는다.
- 모든 제공자 결과와 직접 입력에서 원문과 같은 문장은 저장하지 않는다. 공백·줄바꿈·유니코드 조합 차이는 무시한다. 비운 행에 이전 번역이 있으면 사용자가 적용할 때만 삭제하며, 체크를 해제하면 유지한다.
- `cue.translation`에 번역문·원문 연결·언어·서비스·모델·승인 여부를 저장한다. 원문이 수정되면 오래된 번역은 숨긴다. 시간·단어 강조·LRC 원본은 유지한다.
- 표시 단계에서만 번역을 덧붙인다. 원문과 자동 번역 사이 여백은 **묶음 안 줄 간격**의 60%를 사용하며 **가사 묶음 간격**은 독립적으로 조절한다. 미리보기와 영상 내보내기는 같은 스타일과 배치를 사용한다.

## 검증

모델 패키지 검사, 경로 보호, 취소, 행별 활동 이벤트, 실시간 검토와 복구, 암호화 저장 및 별도 Python 프로세스에서의 재로그인 정보 읽기를 테스트한다. OAuth는 실제 서명 테스트 토큰과 로컬 콜백으로 검증한다. 공식 영어→한국어 모델을 내려받아 네트워크를 차단한 상태에서 앱 내부 CPU 추론과 줄바꿈 유지를 확인한다. 실제 유료 계정의 로그인·번역 품질 평가는 별도이다.
