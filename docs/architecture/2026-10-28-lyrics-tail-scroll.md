# 가사 끝부분의 진입 모션

자동 표시 줄 수가 마지막 가사에 가까워지며 줄어들 때, 현재 창의 마지막 줄을 매번 새로 진입한 줄로 취급했다. 마지막 현재 가사의 이전 표시 여부도 현재 창의 다음 줄 수로 판단해 이미 보였던 가사를 다시 숨겼다. 새 줄에 적용하던 투명도 전환은 화면 안의 빈 공간에서 글자가 생기는 인상을 만들었다.

이전 가사 시점의 표시 범위와 현재 범위를 비교하여 실제로 추가된 다음 가사만 진입 대상으로 계산한다. 이미 표시되던 마지막 가사는 이동을 계속한다. 새로 추가되는 가사는 정상 투명도로 요소의 잘림 경계 밖에서 진입하며, 여러 물리적 줄과 동시에 추가되는 가사들은 같은 이동 거리를 사용해 간격을 유지한다. 아래쪽 진입뿐 아니라 반대 방향과 가로 흐름에도 같은 규칙을 적용한다.

상태는 재생 시각에서 계산하므로 탐색 순서에 의존하지 않는다. 미리보기와 내보내기는 동일한 계산과 렌더러를 사용한다.

검증: `tests/test_lyrics_tail_scroll.py`의 6개 회귀 테스트와 기존 블러·상태·스타일·단어 강조·간주·TTML·내보내기·응답성 테스트를 합쳐 124개 통과. 실제 렌더러의 줄 위치, 투명도, 여러 줄 간격, 네 방향의 진입 경계, 미리보기와 내보내기 이미지 일치 및 역방향 탐색을 검사했다.
