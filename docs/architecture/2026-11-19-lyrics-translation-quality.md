# LLM 가사 번역 품질 및 문맥 일관성 개선 (2026-11-19)

## 배경

JSON 구조 검증이 통과해도 한국어 번역의 자연스러움이나 원문 의미까지 보증하지는 않는다. Qwen3.5:9B 로컬 번역 로그에서 한국어 비문, 반복되는 후렴의 표현 차이, 원문에 없던 한자 혼입, 영어 원문을 빈칸/동일한 원문으로 반환해 번역 불필요로 처리하는 사례가 발견되었다.

## 번역 기억

기존 `reference_translations`는 **완전히 같은 원문이 재등장할 때만** 이전 번역을 참고했다.

변경 후 `context_only.previous_translations`를 모든 다음 LLM 요청에 전달한다. 앞서 완료한 번역의 **원문, 번역문, 원래 ID**가 포함된다. 최근 최대 10줄과 처음 2줄의 문체 기준을 우선으로 하되, 과도한 문맥 확장을 막기 위해 로컬은 1,600자, 클라우드는 2,200자까지 허용한다. 기억은 요청 중 메모리에만 유지한다.

일부 행만 재번역할 때는 사용자 편집/승인 초안을 같은 목표 언어의 참고 문맥으로 보낸다. 이미 선택된 재번역 대상, 실패/미완료/대기 줄과 다른 언어 방향의 번역은 제외한다. 이전 사용자의 수정을 자동 덮어쓰지 않는다.

## 후렴의 표현 통일

완전히 같은 원문이라도 주변 상황에 따라 뜻이 다른 단어는 자동으로 동일 번역으로 고정하지 않는다. **원문이 3회 이상 반복된 긴 구절이거나, 이웃한 소절까지 반복되어 후렴임을 뒷받침할 때** 첫 번째 검증 통과 번역을 후속 반복 위치의 기준으로 활용한다. 이는 노래 내용의 의미적 검증이 아니라 **명확한 반복 후렴의 표기 일관성**을 확보하기 위한 제한적인 규칙이다.

## 번역이 필요한데 '번역 불필요'로 뜨는 문제

`english → korean` 또는 `auto → korean`인 경우 영어 구절을 보수적으로 감지한다. 번역 결과가 빈 문자열, 원문 복사, 영어 문장 그대로이거나 한국어 결과에 **원문에 없던 한자**가 섞이면 해당 ID에 문제를 전달하여 최대 **한 번** 선택 재번역한다. 영어와 한국어가 혼합된 가사에서도 충분히 명확한 영어 구절은 검사한다.

재시도가 끝내 실패하면 `번역 불필요`로 허위 표시하지 않고 실패 행으로 남겨 검토·선택 재번역할 수 있도록 한다. 같은 배치의 나머지 올바른 결과는 부분 성공으로 보존한다. 단독 약어/고유명사, 한국어로 이미 쓰인 구절과 명확히 판단하기 어려운 짧은 말은 과잉 재번역을 피한다.

## 한국어 문장 자연스러움

프롬프트에서 일관된 화자, 존댓말/반말, 조사와 어미, 은유, 슬랭, 반복 표현 등을 강조한다. 한 영어 문장이 여러 cue ID에 나뉜 경우 원문을 **하나의 문장으로 먼저 해석**한 후 의미 순서를 크게 벗어나지 않는 범위에서 인접한 요청 큐 사이의 작은 조사/접속 표현 배치를 조절하도록 허용한다. 단, 원래 cue ID, 개수, 줄바꿈, 타이밍은 보존하고 다른 cue를 새 번역 대상으로 삼지 않는다.

## 검증 범위와 한계

`tests/test_lyrics_translation_quality.py`로 번역 기억 전달, 승인된 초안의 문체 참조, 반복 후렴 표기 통일, 영어 원문 누락/원문 복사/한자 혼입, 성공 결과 보존과 자동 재시도 실패를 검사한다.

한국어 문장이 문법적으로 자연스러운지, 은유가 원문의 뉘앙스를 얼마나 정확히 전달하는지는 **원본 가사와 실제 모델의 출력을 비교하는 별도 품질 평가가 필요**하다. JSON 검사 통과는 번역 품질 보증이 아니라 구조 검사임을 명시하도록 로그 문구도 변경했다.
