# 가사/자막 편집기와 TTML 편집 보호

## 사용자 동작

- 도구 메뉴, 창 제목, 도움말에서 기존 LRC 파일 생성기를 **가사/자막 편집기**로 표시한다. 내부 클래스명·도움말 토픽 ID는 호환성을 위해 유지한다.
- TTML 파일 경로, `format=ttml` 가사, 단어 시간이 있는 내장 가사는 일반 줄 편집기에 전달하기 전에 편집 방식을 선택한다.
- **LRC로 변환**: 단어·음절 시간 및 TTML 전용 필드를 제외하고 일반 편집을 진행한다. 줄 종료 시간은 기존 LRC 편집기 규칙에 따라 재구성된다. 경고에 이 손실을 명시한다.
- **줄만 수정하기**: 별도의 삭제 전용 화면을 연다. 텍스트·시간·순서 편집이 없고 선택한 줄 삭제 및 삭제 취소만 가능하다. 남은 가사 딕셔너리 전체를 깊은 복사로 반환하므로 단어 시간, 종료 시간, 중첩 데이터, 추가 필드가 보존된다.
- **취소**: 편집기를 만들거나 가사를 바꾸지 않는다.

## 진입점과 적용

1. 곡 정보/설정 → 편집기 열기: 편집 전 경고. 파일만 연결되어 있으면 먼저 읽는다. 실패하면 기존 선택을 유지한다.
2. 도구 메뉴에서 한 곡을 선택해 열기: 같은 경고를 거친다. 삭제 전용 모드는 오디오 파일이 없더라도 사용할 수 있다.
3. 빈 편집기를 연 뒤 기존 가사가 있는 오디오를 선택하기: TTML 데이터가 줄 편집 단계로 넘어가기 전에 같은 선택을 한다. 삭제 모드의 결과는 원본 cue를 유지해 반환한다.
4. 일반 편집기의 `_load_initial_cues`에서도 보호 대상이 직접 전달되면 거부하여 경고 우회로 인한 암묵적인 정보 손실을 방지한다.

원본 TTML 파일에는 쓰지 않는다. 편집 결과를 적용하면 이전 파일 경로를 분리하고 프로젝트 내장 가사로 보관한다. 편집기가 새 LRC를 명시적으로 저장한 경우에만 새 경로를 사용한다. 기존 내보내기 기능은 별도 파일 저장 동작을 유지한다.

## 충돌 방지

| 상황 | 처리 |
| --- | --- |
| 내장된 TTML에 파일 경로가 없음 | cue 형식·단어 데이터로 감지 |
| `.TTML` 대문자 확장자 또는 파일만 연결 | 확장자를 소문자로 비교하고 파일을 읽은 뒤 보호 |
| 모든 줄 삭제 | 빈 결과도 적용하고 이전 경로를 비움. 기존 코드의 `if edited_cues` 때문에 삭제가 무시되던 경우를 수정 |
| 줄을 지운 뒤 원본 경로가 남음 | 원본 경로를 비워 이후 로드에서 삭제 전 파일이 다시 연결되지 않도록 처리 |
| 취소 또는 경고창 닫기 | 부모 선택·실제 트랙·원본 파일을 변경하지 않음 |
| 중첩 `words` 필드 공유 | 깊은 복사로 부모·트랙과 편집 결과를 분리 |
| 동일 음원이 여러 트랙에 있음 | 삭제 결과의 적용 대상이 모호하면 곡 선택 또는 곡 설정에서 편집하도록 안내 |
| 불러온 가사 위에 이전 LRC 초안 복구 | 명시적으로 제공된 초기 가사가 있으면 초기 초안 복구를 생략 |
| 편집 중 다른 오디오로 변경 | 초기 가사 선택 상태를 초기화해 새 오디오의 보호 절차를 다시 수행 |

## 곡 정보/설정 화면

- 주요 작업은 **가져오기 / 편집기 열기 / 더보기** 세 버튼으로 묶는다.
- 가져오기 메뉴: 파일, 온라인 검색, 프로젝트 콘텐츠.
- 더보기 메뉴: LRC 내보내기, 연결 해제. 현재 데이터 유무에 따라 비활성화한다.
- 타이밍 보정은 펼침 영역으로 묶는다. 기존 보정값이 있으면 처음부터 펼쳐 보이고, 접어도 값은 유지한다.
- 미리듣기와 곡별 보정, 메타데이터·오디오·영상 탭의 기존 기능은 유지한다.

## 검증

- 기존 주요 회귀 테스트 **151개 통과**.
- 별도로 확장한 TTML·초안·프로젝트 모델·저장 검사 **71개 통과**. 두 실행은 일부 테스트가 중복된다.
- 새 검사에는 선택창의 변환·삭제·취소, 메인 메뉴와 곡 설정 진입점, 편집기 내부에서 뒤늦게 선택한 TTML, 깊은 복사, 전체 삭제, 원본 파일 불변, 모호한 적용 대상, 언어 전환을 포함한다.
- 실제 Qt 화면을 렌더링해 곡 설정, 경고창, 삭제 전용 편집기를 확인했다. 한글·영문 및 타이밍 펼침·접힘 상태에서 곡 설정 최소 크기 **780×540**을 검증했다.
- 프로젝트 파일 손상·적용 실패를 의도적으로 발생시키는 기존 회귀 검사는 오류 로그를 남기지만 테스트는 통과했다.

.venv/Scripts/python.exe -m unittest tests.test_ttml_edit_workflow tests.test_ttml_lyrics tests.test_lrc_draft_service tests.test_project_models tests.test_project_service
