# 가사 행 선택과 상태 경고 — 2026-10-29

가사 검색의 확인 단계는 `적용 체크박스 / 시작 / 종료 / 가사` 표를 사용한다. 처음에는 모든 행을 선택하며 전체 선택·전체 해제와 선택 개수를 제공한다. 선택한 행만 곡에 적용하고 텍스트 복사에도 선택을 반영한다. 모든 행을 해제하면 적용할 수 없다. 다운로드는 제공자가 준 원본 파일을 보존하며 화면에도 이를 명시한다.

적용 경로는 선택한 큐를 깊은 복사하므로 원본 검색 결과와 TTML 단어·음절 타이밍은 변경하지 않는다. 이미 연결된 가사가 있으면 선택된 행만 비교·교체 창으로 전달한다. 교체를 취소하거나 적용이 실패하면 검색 창이 남는다. 성공하면 완료 알림을 표시하고 확인 후 검색 창을 닫는다. 곡 설정에서 연 경우에는 곡 설정의 적용 버튼으로 확정해야 한다는 안내를 별도로 표시한다.

비교·교체 창은 현재 가사와 새 가사를 각각 시간표로 표시한다. 행 개수와 단어 시간 포함 여부를 보여 주며 시간·텍스트·단어 메타데이터가 다른 행을 강조한다. Enter에 의한 뜻밖의 교체를 줄이기 위해 기본 버튼은 현재 가사 유지다. 원본 파일은 변경하지 않는다.

상태 표시줄 맨 왼쪽에 경고 표시를 추가했다. 기존 작업 현황 팝업의 마우스 진입·이탈 지연·고정·화면 안 배치 동작을 재사용하며, 경고 본문은 줄바꿈해 전체 설명을 표시한다. 진행률 표시는 사용하지 않는다. 경고가 해결되면 해당 항목을 제거하고, 남은 경고가 없으면 표시와 고정 팝업을 닫는다.

현재 경고 조건은 다음과 같다.

- TTML/단어 시간 가사가 있는 곡이 있지만 표시할 가사 요소가 없거나 표시 중인 요소의 실시간 가사가 꺼져 있음.
- 가사가 연결되어 있지만 표시 중인 가사 요소가 없음.
- 플레이리스트의 원본 오디오 파일을 찾을 수 없음.
- 모든 곡이 제외되어 미리보기·내보내기에 사용할 곡이 없음.

플레이리스트·요소·언어 변경 시 상태를 갱신하고 연속된 요소 변경은 짧게 모아 처리한다. 단어 강조를 사용할지 여부는 사용자가 선택하며 경고가 설정을 자동으로 바꾸지는 않는다.

검증에는 선택된 TTML 행과 원본 메타데이터 보존, 전체 해제 방지, 교체 취소 시 창 유지, 성공 알림·종료, 경고 고정과 조건 해소, 파일 누락·곡 제외, 표 기반 비교를 포함한다. 기존 검색·가사 편집·작업 현황·메인 창 관련 회귀 검사도 실행했다.

관련 회귀 검사 11개 모듈, 389개 테스트가 모두 통과했다. 마지막 비교 표시·경고 갱신 보완 후 검색 및 새 기능 검사 27개를 다시 실행해 통과했다. 소스 컴파일과 공백 검사도 통과했다.
