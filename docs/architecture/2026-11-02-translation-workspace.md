# 가사 번역 통합 작업 공간과 별도 설정 창

## 창별 역할과 흐름

| 창 | 역할 | 연결 |
| --- | --- | --- |
| 가사 번역 · 검토 및 편집 | 위쪽에서 언어·방식·서비스 확인과 번역 시작·진행·취소, 아래쪽에서 원문·번역 비교와 편집·필터·재번역·초안 저장·적용 | 서비스 및 모델 설정, 번역문 스타일 |
| 번역 서비스 및 모델 설정 | 현재 방식에 해당하는 제공자·인증·모델 선택, 모델 조회·연결 테스트, 언어 모델 설치 | 로컬 LLM 관리자, 고급 설정, OpenAI 계정 관리 |
| 로컬 LLM 관리자 | 설치 모델 검색, 추천 모델 비교·다운로드, 로드·해제·삭제 | 설치된 모델 / 다운로드·모델 비교 / 고급 관리 탭 |
| 고급 번역 설정 | 문체 등 추가 지침, 클라우드 모델 ID 직접 입력, 로컬 서버 주소, 기본 프롬프트 열람 | 서비스 설정과 같은 값을 공유 |
| 번역 가사 스타일 | 기존 캔버스 가사 소스의 표시·글꼴·크기·색 설정 | 통합 번역 창에서 직접 열기 |

설정이 준비되어 있으면 메인 창에서 **번역 시작 → 결과 검토 → 선택한 N줄 적용**으로 진행한다. 설정 창을 열지 않아도 된다. 설정이 부족하면 준비할 창을 표시하고 현재 언어를 유지한다. 번역 중 같은 창의 표에 실시간 결과를 표시한다. 성공하면 표로 포커스를 옮기며 바로 편집·적용한다. 별도 검토 창이나 결과 창을 여는 버튼은 없다.

## 상태와 수명

- `TranslationDraft`는 원문 사본, 행별 초안·적용 체크·상태·수정 여부·서비스/모델/언어 정보를 보관한다. 곡 ID와 원문/기존 번역의 해시가 같은 작업만 복원한다. 설정 파일에 초안을 저장하며 프로젝트 형식은 바꾸지 않는다. 인증 키·서버 주소·추가 지침은 초안에 넣지 않는다.
- `TranslationWorkflow`는 공유 `TranslationWorker` 하나를 소유한다. 설정 준비와 번역은 이 실행 경로를 사용하고, 네트워크·추론·모델 설치를 UI 스레드에서 실행하지 않는다. 진행·상태·완료·사용 가능 여부는 Signal/Slot으로 연결한다. 실제 번역 어댑터와 프롬프트·렌더링 계약은 유지한다.
- 서비스·고급·로컬 관리자 창은 통합 번역 창의 자식인 독립 창이다. 결과 편집기는 통합 창에 배치한 `TranslationReviewPanel(QWidget)`이며 독립 창이 아니다. 고급 설정이나 모델 관리자를 서비스 창 안에 중첩하지 않는다. 별도 OpenAI 로그인과 기존 스타일 편집만 목적이 분명한 하위 창으로 사용한다.
- 서비스·고급 설정 창을 닫아도 공유 번역 작업은 계속된다. 메인 창을 닫으면 취소 이벤트를 설정하고 작업 종료 신호가 온 뒤 닫는다. 메인 창을 삭제하기 전 로컬 모델 관리 작업도 취소·종료를 기다린다. 강제 스레드 종료나 UI 스레드의 블로킹 대기는 하지 않는다.
- 로컬 모델 관리자 자체의 다운로드 수명은 기존 취소·종료 경로를 유지한다. 관리자 사용 중에는 번역 시작을 막아 삭제·로드와 추론의 충돌을 피한다. 다운로드 진행·취소·선택 모델 사용은 스크롤 밖에 고정한다. 별칭과 상세 메타데이터는 **고급 관리** 탭으로 옮긴다.

## 편집·재번역·적용 계약

- 체크 상자는 적용할 행을 정한다. 표의 클릭·Ctrl·Shift 강조는 재번역할 행을 정하며 버튼 도움말에 차이를 설명한다.
- 선택 행 재번역은 원래 가사 전체에서 해당 ID만 요청한다. 앞뒤 문맥을 유지하며 다른 행의 직접 수정·체크·언어·제공자 정보를 보존한다.
- 실패·취소 시 임시 실시간 결과를 이전 초안으로 되돌린다. 실패 행은 원인과 함께 표시하고 적용 체크를 해제한다. 취소는 이전 체크와 미완료 상태까지 복원한다.
- 편집은 **수정됨**으로 표시하고 수정한 행만 필터링할 수 있다. 편집 셀은 여러 줄 입력을 지원한다. Ctrl+Enter로 셀 편집을 완료하고 Ctrl+S로 초안을 저장한다.
- 적용은 행별 서비스·모델·언어 정보를 유지한다. 원문·타이밍·단어 강조와 프로젝트 저장 구조는 바꾸지 않는다. 적용 성공 시 저장 초안을 지운다. 창 닫기는 초안을 보존한다.
- 스타일은 캔버스 소스에 속하므로 번역 초안과 따로 적용한다. 가사 소스가 여러 개면 선택하고, 없으면 가사 소스 추가 안내를 표시한다.

## 화면 검증 재현

`python scripts/capture_translation_workspace.py`는 실제 계정이나 서버 없이 예제 데이터로 통합 번역 창과 네 설정·관리 창 및 최소 크기 화면을 `work/translation-workspace/default`에 생성한다. 앱의 `apply_studio_style`을 사용한다. `--suffix dpi150` 등과 `QT_SCALE_FACTOR=1.5`, `2`를 조합해 배율별 결과를 생성할 수 있다. 이 스크린샷은 실제 Qt 위젯의 오프스크린 렌더링이며 실제 서비스 연결·번역 품질의 증거는 아니다.

통합 창은 기본 설정을 짧은 상단 영역에 배치하고 원문·번역 표에 나머지 공간을 제공한다. 서비스·고급 창은 내용 스크롤을 제공한다. 검토 표는 두 문장을 넓게 배치하고 열 너비에 맞춰 여러 줄 높이를 갱신한다. 모델 관리 창은 내용 스크롤과 고정 하단 작업 영역을 함께 사용한다. 실제 모니터 사이 이동이나 운영체제 스크린 리더의 동작은 수동 확인 대상이다.

관련 테스트는 `test_translation_workspace`, `test_lyrics_translation`, `test_lyrics_translation_prompt`, `test_local_translation`, `test_local_llm`에 있다. 저장·인증·렌더링 계약 검증은 기존 테스트를 유지하고, 번역·검토의 같은 창 배치·설정 창 이동·초안 복원·선택 재번역·오류 필터·키보드 닫기·스타일 연결과 작업 중 창 닫기를 추가 검증한다.

## 검증 중 확인한 환경 제약

- 최종 통합 UI 검증은 번역 작업 공간·기존 번역·프롬프트·로컬 LLM·도움말·아키텍처·Qt 작업 수명 7개 모듈의 102건을 통과했다. `work/translation-workspace/unified-final-tests.json`에 실행 결과를 저장했다. 기본·최소 크기와 150%·200% 배율에서 통합 화면 및 별도 설정 창을 렌더링했다.
- OAuth 로컬 콜백 테스트는 샌드박스의 소켓 제한으로 시간 초과가 발생했다. 외부 요청을 보내지 않는 테스트임을 확인하고 제한 밖에서 다시 실행했을 때 7건 모두 통과했다.
- 기존 실물 Argos 모델 설치 테스트는 임시 모델 디렉터리의 `rename`에서 간헐적으로 `PermissionError: WinError 5`가 발생했다. 추적 실행에서는 51건 연속 통과했으나 일반 반복 실행에서는 재발했다. 해당 설치 구현은 이번 UI 변경에서 수정하지 않았다. 실제 계정 번역 품질과 운영체제의 모니터 간 DPI 이동은 수동 확인 대상이다.
