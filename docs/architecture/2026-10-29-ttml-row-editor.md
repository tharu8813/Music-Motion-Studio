# TTML 줄 편집기 선택 및 창 종료 수정 — 2026-10-29

삭제 후 표를 다시 채울 때 기존 선택과 현재 셀이 남아, 같은 화면 인덱스에 들어온 다음 줄이 다시 삭제될 수 있었다. 새로고침 전후에 선택과 현재 셀을 모두 초기화하고, 다시 선택하기 전까지 삭제 버튼을 비활성화한다. 삭제 취소 후에도 선택을 초기화한다. 삭제 단축키의 자동 반복도 막았다.

곡 정보/설정에서 편집기를 마치면 상위 창의 `_accept()`까지 호출하던 경로를 제거했다. 편집 완료는 결과를 곡 설정에 임시 반영하고, 최종 적용은 곡 설정의 적용 버튼으로 확정한다. 자식 편집기의 완료·X 닫기·Esc가 상위 곡 설정 창을 닫지 않도록 실제 중첩 모달 테스트를 추가했다. 닫기·취소는 자식 창의 편집을 버리고 상위 창을 유지한다.

UI는 원본 줄 번호, 읽기 쉬운 시간 표시, 여러 줄 선택, 전체 선택·선택 해제, 선택 개수가 포함된 삭제 버튼, 삭제 결과와 되돌리기 안내를 제공한다. 삭제 후 번호를 다시 매기지 않고 원본 번호를 표시하므로 어떤 줄을 남겼는지 알 수 있다. 하단 안내는 편집기 완료와 상위 창 적용의 차이를 설명한다. 텍스트·순서·타이밍·단어 정보의 직접 수정은 계속 제한한다.
