# LRCLIB 검색 복원

기존 KuGou와 AMLL을 유지하고 LRCLIB를 세 번째 검색 공급자로 추가했다. 기본 전체 검색과 개별 LRCLIB 검색 모두 지원하며, 검색 창의 설명·공급자 메뉴·출처 링크에도 반영했다.

- [LRCLIB 공식 API](https://lrclib.net/docs)의 `/api/search`에 `track_name`과 선택적인 `artist_name`을 보낸다. 앨범과 길이는 검색 조건에 넣지 않고 기존 결과 정렬에만 사용한다.
- 검색 응답의 레코드 ID와 원문을 보존한다. 결과 선택 시 다른 버전을 재검색하지 않고 해당 원문의 LRC 또는 일반 텍스트를 가져온다. LRC에 없는 단어 시간은 생성하지 않는다.
- 기본 시간 정보 필터는 일반 텍스트 결과를 제외한다. 필터를 해제하면 일반 가사를 복사·저장할 수 있다. 반주곡 및 가사가 없는 레코드는 제외한다.
- 기존 요청 간격·응답 크기 제한·캐시·취소·HTTP 429 대기 처리를 공유한다. 한 공급자가 실패해도 다른 공급자의 결과를 유지한다.

검증: 검색 서비스·공급자·검색 창·메인 창 연결 테스트 75개 통과. 실제 공개 API에서 `ME! / Taylor Swift` 검색 결과 20개와 선택 결과 LRC 64줄을 확인했다. 이는 확인 시점의 결과이며 제공자 데이터에 따라 바뀔 수 있다.
