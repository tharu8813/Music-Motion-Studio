## 화면

다른 편집 창과 같은 `dialogTitle`, `card`, 공통 팔레트와 아이콘 체계를 사용한다. 창 제목과 대상 요소를 분리하고 미리보기·현재 값·키프레임을 각각 패널로 정리했다. 미리보기 도구는 작은 도구 버튼으로 묶고 재생·시간·미리보기 길이를 타임라인 위에 배치했다. Undo/Redo는 키프레임 패널 머리글에 둔다. 행마다 반복되던 큰 버튼과 별도 초록 계열 색상은 공통 도구 버튼과 색상 토큰으로 교체했다.

프리셋 팝업도 같은 색상 토큰과 선택·호버·포커스 스타일을 사용한다. 각 행의 프리셋 버튼에는 현재 곡선의 작은 그래프를 표시한다. 스타일 변경은 이 창과 프리셋 팝업에 한정하는 QSS 선택자를 사용한다.

## 미리보기 방향

- **곡 시작:** 효과 시작부터 재생하고 효과가 끝난 뒤에만 읽기 전용 여유 구간을 둔다. 효과 시작 전으로는 탐색하지 않는다.
- **곡 끝:** 효과 이전에만 읽기 전용 여유 구간을 두고 효과 끝에서 재생을 마친다. 효과 이후로는 탐색하지 않는다.

시간 입력 이름도 `효과 후 미리보기` / `효과 전 미리보기`로 바뀐다. 스크럽·처음·반복 재생 모두 같은 범위를 따른다. 허용 범위를 벗어난 탐색은 해당 경계로 제한한다. 회색 여유 구간에서는 기존처럼 키프레임·속성·Canvas 핸들을 편집할 수 없다. 소수 지속 시간의 끝에서 다시 재생했을 때 정상적으로 처음으로 돌아가도록 재생 범위의 정밀도도 맞췄다.

## 트랙 활성화와 선택

X, Y, 크기, 회전, 투명도 행의 체크박스로 각 속성의 모션을 켜고 끈다. 끈 트랙의 키프레임 시간·값·보간·사용자 지정 곡선은 보존한다. 해당 속성의 미리보기와 출력만 상대 기본값(X/Y·회전 0, 크기·투명도 1)을 사용한다. 다시 켜면 기존 모션이 복원된다. 트랙 설정도 시작·끝에서 독립적이고 프로젝트 저장·복원 및 Undo/Redo 대상이다.

꺼진 트랙의 숫자와 추가·삭제·이동·곡선 편집은 잠긴다. Canvas에서는 꺼진 크기·회전 핸들을 숨기고, X/Y 이동은 켜진 축만 변경한다. 실제 Source의 기본값을 변경하지 않는다.

이름이나 재생 바를 누르면 해당 트랙을 선택한다. 선택한 행의 이름·좌우 도구 영역·타임라인 배경을 함께 강조하고, 인접 두 점 사이에는 추가 강조를 표시한다. 오른쪽 현재 값 패널에서도 선택한 속성과 편집 가능/꺼짐/미리보기 전용 상태를 표시한다.

## 검증

Windows 네이티브 Qt에서 관련 5개 모듈의 **50개 테스트가 모두 통과**했다. 실제 FFmpeg MP4 비교, GPU 비교, 저장·복원, 활성화 상태 보존, 트랙 선택·Undo/Redo, 방향별 탐색 제한을 포함한다. 별도의 영어 150% 배율 GUI **19개도 모두 통과**했다. 반복 실행은 총계에 중복 합산하지 않았으며 전체 저장소 재실행 결과는 아니다.

`compileall`, `git diff --check`, 공통 스타일시트 토큰·아이콘 자원 검증을 통과했다. [검증 JSON](benchmarks/2026-11-03-motion-editor-ui.json)에 실행 결과를 보존한다. 화면은 `work/motion-editor-redesign-ko.png`, `work/motion-editor-redesign-en-150.png`에 있다.

주요 수정 파일은 `custom_motion.py`, `custom_motion_dialog.py`, `motion_canvas.py`, `motion_timeline.py`, `motion_curve_presets.py`, 공통 `studio.qss`와 `studio_icons.py`, 사용자 지정 모션 테스트 두 모듈이다. 기존 영상 정지 화면·예시 음악 반응 등의 제한은 유지한다.
