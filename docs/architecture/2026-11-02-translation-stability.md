# 가사 번역 안정성·데이터 보존 점검

## 확인한 문제와 처리

| 항목 | 코드에서 확인한 동작 | 개선 |
| --- | --- | --- |
| 적용과 최종 저장 | 번역 창과 부모 창이 모두 초안을 지웠지만 곡 정보 창은 아직 임시 변경 상태 | 적용·닫기 전에 복구 초안을 동기 저장하고 삭제하지 않는다. 곡 정보 창의 적용과 프로젝트 저장이 필요하다고 안내한다. |
| 여러 번 적용 후 취소 | 기존 번역까지 포함한 해시가 바뀌어 최초 초안과 후속 편집이 서로 다른 키에 저장됨 | 같은 곡·원문·타이밍의 알려진 적용 전후 해시를 연결해 최신 편집을 복원한다. 관계없는 프로젝트 번역은 초안으로 덮어쓰지 않는다. |
| 빈 번역문 적용 | 빈 문자열뿐 아니라 원문과 같은 번역도 정규화 후 기존 번역 삭제로 처리 | 실제 삭제될 행 번호·개수를 확인하고 기본값을 취소로 둔다. 체크 해제한 행은 경고·삭제 대상이 아니다. |
| Argos 설치 | 정상 패키지도 `ready.rename(target)`의 Windows 접근 거부가 잘못된 패키지 오류로 표시됨 | 공유 잠금 오류만 제한적으로 재시도하고, 모델별 프로세스 간 게시 잠금을 사용한다. 영구 접근 거부는 잠금·폴더 권한·공간 오류로 구분한다. |
| 언어 선택 | 제공자 전환 때마다 제공자별 원문·목표 언어를 다시 로드 | 첫 실행에 활성 제공자의 과거 언어를 한 번 이전하고 공통 `translation/languages`에 저장한다. 방식 변경으로 자동 감지를 특정 언어로 바꾸지 않는다. |
| 검토 위치 | 진행 이벤트가 매번 `scrollToItem` 호출, 완료 때 포커스 이동 | **진행 행 따라가기** 기본 해제. 사용자가 켠 경우만 이동하고, 해제 상태에서는 스크롤 위치를 보존한다. 완료 후 포커스도 강제로 옮기지 않는다. |
| 준비 안내 | 설정 형식만 유효해도 **번역 준비 완료** 표시 | 필수 설정 입력 / 모델 파일 존재 / 실제 연결·모델 조회 / 확인 실패를 구분한다. 연결 확인은 자격 증명·서버가 바뀌거나 5분이 지나면 미확인으로 되돌린다. 안내는 30초마다 갱신하며 자동으로 서버에 요청하지 않는다. |
| 초안 수명 | 삭제 UI 없음, 저장 실패 확인 없음, 이미 저장된 번역 열람도 초안으로 저장 | 실제 변경이 있을 때 보존한다. **초안 삭제…**로 현재 곡 보관본과 편집을 삭제한다. 저장 오류는 표시하고 적용·닫기를 중단해 메모리 편집을 유지한다. |

## 초안 보관과 복원 계약

번역 적용은 곡 정보 창에 임시 반영하는 단계다. 곡 정보 창의 **적용** 뒤 프로젝트를 저장한다. 그 전후로 번역 초안은 기기에 계속 남는다. 곡 정보 창을 취소하면 원래 곡은 바뀌지 않으며, 같은 곡의 번역 창에서 최신 복구 초안을 다시 연다.

초안은 QSettings의 `translation/drafts`에 저장한다. 기존 v1을 읽고, 새 v2에는 저장 시각·곡 식별자 해시·원문 해시·적용 전후 해시와 행 상태를 추가한다. 프로젝트 파일, 번역문 메타데이터, 렌더링 및 타이밍 형식은 바꾸지 않는다. 원문·시간·단어 정보가 달라지거나 알려진 적용 이력과 무관한 기존 번역이면 자동 복원하지 않는다.

보관 기간과 개수에 따른 자동 삭제는 하지 않는다. 사용자가 **초안 삭제…**로 현재 곡의 새 형식 보관본과 현재 스냅샷을 명시적으로 삭제한다. 다른 곡과 프로젝트 가사는 바꾸지 않는다. v1에는 곡 식별 메타데이터가 없으므로 현재 열어 확인한 v1 스냅샷만 안전하게 삭제할 수 있다. 삭제 뒤 새 편집·번역이 생기기 전까지 자동 저장으로 보관본을 다시 만들지 않는다.

인증 키·액세스 토큰·서버 주소·추가 프롬프트는 초안에 넣지 않는다. v1 복원 때도 설정에서 이러한 필드를 제거한 뒤 새 형식으로 저장한다. 가사와 번역문 자체는 복구를 위해 기기에 저장되며, 프로젝트를 다른 PC로 옮겨도 복구 초안은 함께 옮겨지지 않는다. 정상 종료는 편집 셀을 확정하고 동기 저장한다. 비정상 종료 직전에는 최대 자동 저장 지연(500ms)의 편집이 남을 수 있다.

## Windows 모델 설치 조사

앞선 실제 모델 테스트의 실패 지점은 압축 검사나 추론이 아니라, 검증된 임시 모델 디렉터리를 최종 이름으로 옮기는 `Path.rename`이었다. Windows 네이티브 `CreateFileW`로 모델 파일을 삭제 공유 없이 연 상태에서 같은 오류를 재현했다. 핸들을 닫으면 재시도가 성공했다. 이는 파일 공유 잠금으로 발생할 수 있는 실패 경로를 확인한 것이다. 원래 간헐 오류를 일으킨 외부 프로세스가 백신인지, 인덱서인지 또는 다른 프로세스인지는 특정하지 않았다. Windows 공유 플래그와 이동 조건은 [CreateFileW](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-createfilew), [MoveFileExW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw)를 참고했다.

- Windows 오류 5/32/33에만 최대 7회, 총 대기 약 2.35초로 재시도한다. 대기는 취소 이벤트로 중단할 수 있으며 무한 반복하지 않는다.
- 같은 모델의 최종 게시에 [QLockFile](https://doc.qt.io/qtforpython-6/PySide6/QtCore/QLockFile.html)을 사용한다. 대기는 최대 5초이며 다른 프로세스의 유효한 잠금을 강제로 제거하지 않는다. 경합 후 이미 설치된 동일 모델이 있으면 검증해 재사용한다.
- 임시 디렉터리는 최종 모델과 같은 관리 폴더에 두고, 검증 뒤 디렉터리 이름 변경으로 게시한다. 기존 모델을 먼저 지우거나 덮어쓰지 않는다. 최종 설치 경로에서 부분 복사된 모델을 노출하지 않는다.
- 임시 디렉터리 정리도 잠금 오류를 재시도한다. 현재 작업이 만든 `.install-*`이 관리 폴더 내부인지 확인한 뒤 삭제한다. 정리만 끝내지 못했을 때는 설치 성공을 실패로 뒤집지 않고 로그를 남긴다. 오래 유지되는 외부 잠금에는 숨겨진 임시 파일이 남을 수 있으며, 다른 작업의 폴더를 임의로 지우지 않는다.
- 작은 가짜 패키지로 스레드·별도 프로세스 중복 설치, 네이티브 핸들 잠금과 해제, 영구 거부, 취소 및 정리 경계를 검증한다. 실제 모델 검증은 이미 있던 `work/translation-checks/en-ko.argosmodel`을 사용한다. 새 대용량 모델을 다운로드하지 않는다.

| 요청량·비용 안내 | 클라우드 전송 고지와 제공자 요금·구독 한도 안내가 있다. | 중간. 실제 토큰 수는 문맥·배치·응답·모델에 따라 달라 단순 문자 수를 가격으로 표시하지 않는다. 이번 작업에서는 유료 요청이나 가격 조회를 하지 않았다. |

## 검증 범위

`tests/test_translation_safety.py`에 핵심 회귀 테스트를 추가했다. 실행 보고서는 `work/translation-stability-final.json`, `work/translation-stability-repeated.json`, `work/translation-safety-recovery.json`에 있다. 반복 검증은 로컬 번역 및 안전성 모듈 각각 5회, 총 150건을 통과했다. 적용 이력 복원과 삭제 후 자동 저장 테스트를 추가한 뒤 관련 두 모듈 29건도 통과했다.

최종 수정 후 핵심 9개 모듈 **136건 모두 통과**(`work/translation-stability-verified.json`). 별도 호환성 검증은 19개 모듈에서 **260건 통과, 1건 생략, 실패 0건**이었다. 생략은 `PLAYLIST_CANVAS_TEST_FFMPEG`가 필요한 FFmpeg 실믹싱 테스트다. TTML·LRC·가사 사이드카·프로젝트 저장·자막 내보내기·곡 설정과 기존 번역 검증을 포함했다. 통합 창의 기본/최소 크기 화면은 `work/translation-workspace/stability`에 생성해 확인했다.

실제 유료 API·계정 한도, 모든 외부 잠금 프로그램 조합, 비정상 전원 종료 및 모니터 간 DPI 전환은 검증하지 않았다. 준비 안내는 연결 확인을 추론 실행 성공이나 남은 메모리·요금 한도 보장으로 표현하지 않는다.
