# 가사 공백 이후 블러 복원과 마지막 가사 처리

공백에 남은 TTML 가사의 블러를 0으로 강제하던 처리가 다음 가사 시작 순간 해제됐다. 그동안 밝기 강조는 이미 줄어든 상태여서 블러가 곧바로 전체 값으로 돌아왔다. 또한 마지막 가사 뒤에도 공백 플래그가 계속 참이었고, 현재 가사가 아닌 중앙 유지 줄을 다음 가사 스타일로 처리해 마지막 줄에 이전 가사 블러가 적용되지 않았다.

현재 동작:

- 다음 가사가 남은 공백에서는 실제로 마지막에 끝난 가사 묶음만 선명하게 유지한다.
- 다음 가사 시작 후에는 그 묶음의 블러만 독립적으로 0에서 설정값까지 복원한다. 전환 시간과 이징을 사용하고 밝기·글자 크기 강조를 다시 켜지 않는다.
- 전체 가사 종료는 공백과 구분한다. 마지막 묶음도 이전 가사 스타일로 돌아가며, 애니메이션을 사용하면 기존 종료 전환 동안 블러가 적용된다. 애니메이션 없음은 즉시 적용한다.
- 겹치는 가사와 여러 줄의 원래 cue ID를 기준으로 적용하여 이미 끝난 다른 줄의 블러를 불필요하게 초기화하지 않는다.
- 기존 가사 시계의 0.5ms 경계 허용치를 종료·복원 계산에도 적용해 경계 직전에 전체 블러가 한 프레임 깜박이는 상황을 방지한다.
- 상태는 재생 시각에서 계산하고 캡처 후 복구한다. 탐색 순서에 의존하지 않는다. 내보내기 프레임 병합 키에도 복원 진행률을 포함한다.

검증: 상태·렌더링·겹치는 가사·단어 강조·간주·TTML·내보내기·응답성 테스트 **118개 통과**. 실제 렌더러에 전달되는 블러 반경이 공백과 다음 시작에서 0이며, 전환 중 단조 증가하고 마지막 종료 후 설정값에 도달함을 확인했다. 미리보기와 내보내기 이미지 일치, 역방향 탐색, 짧은 공백, 여러 마지막 줄, 타이밍 보정, 모션·단어 변화가 없는 블러 프레임의 병합 방지도 검사했다.
