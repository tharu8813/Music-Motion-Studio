# 시각 타임라인으로 편집 경로 통합

2026-11-04. 메인 타임라인의 숫자 편집 화면을 제거하고 기존 시간 데이터와 프로젝트 저장 형식은 유지했다.

- 시각/숫자 모드 선택, 음악·요소의 숫자 입력 표와 우클릭의 숫자 편집 메뉴를 제거했다. 재생 위치도 편집할 수 없는 시간 표시로 바꿨다.
- 곡·요소 막대를 끌어 시작 위치를 옮기고, 요소 양끝 손잡이로 노출 길이를 조절한다. 마우스를 놓을 때만 모델을 갱신하므로 기존 프로젝트 Undo와 연결된다. Esc는 미반영 드래그를 취소한다.
- 레이어 이름으로 선택하고 선택 행을 강조한다. 선택·호버 시 크고 선명한 길이 손잡이를 표시한다.
- 막대 두 번 클릭 또는 **선택 확대**로 짧은 구간을 확대한다. 시작·끝 버튼과 `[` / `]`로 경계에 재생 커서를 맞춘다. `F`는 전체 보기, `Enter`는 현재 위치 미리보기다.
- 곡을 선택하면 위·아래 순서 버튼을 표시하며 `Ctrl+↑/↓`도 지원한다. 원본 곡 길이와 기존 이어붙이기 규칙은 유지한다.
- 드래그 중 시작·종료·길이 안내를 막대 가까이에 표시한다. 3px 미만 움직임은 선택으로 처리하고, 실제 드래그가 시작된 뒤에만 자동 스크롤한다. 드래그 중 확대·키보드 이동으로 기준이 바뀌지 않게 하며 패널을 숨기면 미반영 조작과 타이머를 정리한다.
- 스냅, 확대/축소, 가로·세로 스크롤, 잠금, 곡 끝까지 표시와 자동 이어붙이기는 유지한다. 이전 키프레임 데이터도 보존하며 기존 재생 위치 평가 연결을 유지한다.
- 한국어·영어 도움말과 타임라인 화면 이미지를 현재 UI에 맞췄다.

주요 파일은 `app/timeline/timeline_panel.py`, `visual_timeline.py`, `app/ui/main_window.py`, `app/dialogs/help_content.py`다. 제거한 화면을 가정하던 테스트는 시각 선택·시간 표시·순서 변경·이전 데이터 보존을 검증하도록 바꿨다. 숫자 입력 위젯과 메뉴가 실제로 없다는 검사도 추가했다.

최종 Windows 네이티브 실행에서 사용자 지정 모션·이전 키프레임 호환·타임라인 모델·도움말·시각 타임라인 **71개가 모두 통과**했다. 영어 150% DPI에서는 시각 타임라인 **10개를 재실행해 모두 통과**했다. 실행 중복을 합쳐 고유 테스트 수라고 세지 않는다. `compileall`과 `git diff --check`도 통과했다. [실행별 검증 JSON](benchmarks/2026-11-04-visual-only-timeline.json)에 원본 결과를 보존한다.

메인 창·내보내기·플레이리스트·미리보기·프로젝트·반응형 화면의 넓은 회귀 실행도 수행했다. 최초 실행에서 제거한 표를 전제로 한 메인 창 테스트를 음악 행 기준으로 고치고 해당 테스트를 네이티브로 재실행해 통과했다. 새 우클릭 메뉴 테스트의 모달 메뉴 모의 처리가 시간 초과되어 비차단 액션 메뉴 모의로 바꾼 뒤 시각 테스트 전체를 재검증했다. 기존의 이동 1회 반영·Esc 취소·잠금·스냅·Undo·저장 데이터 검사는 유지했다.

1000×460, 680×340 창을 한국어·영어, 100%·150% DPI로 캡처하고 도구의 접근성과 타이밍 데이터 보존을 확인했다. 화면은 `work/visual-only-timeline/`, `work/visual-only-timeline-150/`에서 확인할 수 있다. 프로그램 도움말의 `app/resources/help/ko/canvas_timeline.png`, `en/canvas_timeline.png`도 갱신했다.
