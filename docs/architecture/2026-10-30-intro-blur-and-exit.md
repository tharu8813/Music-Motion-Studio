# 인트로 대기 줄의 이전 가사 블러와 퇴장 효과

## 블러 처리

TTML 가사의 실제 공백에서는 직전 가사를 읽을 수 있도록 `gap_unblurred`를 적용한다. 기존 렌더러는 인트로 대기 줄의 이전 가사 스타일을 계산한 뒤 이 값을 적용해, 대기 줄 위에 있는 직전 가사까지 선명하게 만들었다. 대기 줄 퇴장 중에는 이미 흐려진 가사에 공백 블러 복원 진행률을 다시 곱해 블러가 잠시 약해지는 문제도 있었다.

공백의 기본 가독성 처리를 먼저 계산하고 인트로의 역할별 스타일을 그 위에 보간하도록 순서를 변경했다. 인트로가 퇴장할 때는 이미 적용된 직전 가사 블러를 유지한다. 인트로가 없는 공백의 가독성 처리는 유지한다.

## 표시와 퇴장

대기 표시 스타일에 공전하는 점(`orbit`), 퍼지는 파동(`ripple`), 흐르는 빛(`comet`)을 추가했다. 기존 다섯 종류와 합쳐 여덟 종류를 선택할 수 있다. 모두 작은 벡터 도형으로 그린다.

`subtitle_intro_exit`는 대기 표시와 독립적인 퇴장 선택이다. 기본값은 부드럽게 축소(`shrink`)이며, 서서히 사라짐(`fade`), 흘러 사라짐(`drift`), 퍼지며 사라짐(`spread`), 차례로 지워짐(`wipe`)을 제공한다. `Source`, `LyricsComponent`, 인트로 고급 설정과 설정창에 같은 필드를 연결했다. 이 필드가 없는 프로젝트는 기본값을 사용한다.

퇴장 중 표시 내부의 마지막 자세를 유지하고, 0에서 1로 진행하는 부드러운 곡선으로 불투명도를 줄인다. 일반 가사 효과의 바운스·글로우·줌 펄스를 퇴장 표시에 중복 적용하지 않는다. 대기 줄 전체의 이동과 가사 배치는 기존 전환 시간을 계속 따르며, 전체 애니메이션이 ‘없음’이면 퇴장도 즉시 끝난다.

`자막 전환 설정 → 인트로`에서 표시 스타일과 퇴장 효과를 따로 지정한다. 예시 미리보기에는 ‘첫 가사 · 퇴장 확인’, ‘간주 · 퇴장 확인’을 추가해 긴 대기 구간을 건너뛰고 퇴장 전후를 반복해서 볼 수 있다.

## 검증

`tests/test_lyrics_intro.py`에 다음 검사를 추가했다.

- 일반 가사 및 TTML, 네 이동 방향에서 대기 줄 진입·대기·퇴장 중 이전 가사의 블러와 여러 줄의 일관성.
- 다섯 퇴장 효과의 단조로운 불투명도 감소, 시작·끝 상태와 실제 렌더링 결과의 차이.
- 설정 저장·복원, 기존 프로젝트 기본값, 잘못된 값 거부, 인트로 고급 모드의 적용 범위와 원본 보존.
- 모든 퇴장 효과의 미리보기·내보내기 이미지 일치, 1배·2배 해상도와 역방향 탐색의 재현성.
- 퇴장 확인 미리보기가 실제 가사 시작 직전으로 이동하는지 확인.

가사·TTML·설정·프로젝트·내보내기 관련 28개 모듈, 339개 테스트 중 338개가 통과했다. 기존 비교창 색상 테스트 1개는 기대값 `#40392b`와 작업 전부터 적용된 UI 색상 `#433c30`의 차이로 동일하게 실패한다. 해당 색상과 테스트는 변경하지 않았다.
