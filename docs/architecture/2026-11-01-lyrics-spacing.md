# 가사 묶음과 줄 간격

- **묶음 안 줄 간격**(`subtitle_line_spacing`)은 같은 큐 안의 원래 줄바꿈 사이에 넣는 여백이다. 자동 줄바꿈으로 이어지는 행에는 이 추가 여백을 넣지 않는다. 원문에서 자동 번역문으로 넘어갈 때는 여백의 60%를 사용해 두 문장이 한 묶음임을 보여 준다.
- **가사 묶음 간격**(`subtitle_cue_spacing`)은 이전·현재·다음 큐 사이의 여백이다. 글자 높이를 제외한 여백을 의미하며 묶음 안 간격과 독립적이다. 가로 흐름에서는 가사 열 사이의 여백과 줄바꿈 너비 계산에 사용한다.
- 두 속성은 기본 속성 패널과 자막 전환 설정의 **줄 배치** 탭에서 조절한다. 고급 줄 배치를 끄면 기본값을 사용하며 고급 초안은 보존한다. 미리보기의 **여러 줄 예시**는 가사 데이터나 적용 설정을 변경하지 않는다.
- 새 속성이 없는 모델은 생성 시 기존 줄 간격으로 초기화하고 실제 숫자를 저장한다. 이전 고급 설정에도 같은 초기화를 적용한다. 이후 줄 간격을 편집해도 묶음 간격은 바뀌지 않는다. 저장·복제·실행 취소는 기존 Source 및 LyricsComponent 경로를 사용한다.
- 실제 배치와 자동 문맥 범위는 같은 행 배치 함수를 사용한다. 묶음 간격의 차이는 각 큐의 앞뒤에 절반씩 포함해 중심, 영역 크기와 전환 이동 거리가 일치하게 한다. 미리보기와 내보내기도 같은 배치 결과를 사용한다.
