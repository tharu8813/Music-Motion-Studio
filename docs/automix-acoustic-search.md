# AutoMix 음향 기반 전환 선택

AutoMix는 전환 길이를 먼저 고르고 효과를 나중에 붙이는 대신, 큐·길이·저음/보컬 인계를 함께 비교한다.
Basic과 Beat This!/ONNX가 이미 디코딩한 PCM에서 1초 단위 타격감·음색과 100ms 단위 대역별 전력을 측정한다.
추가 디코딩이나 모델 다운로드 없이 추출하고, 새 분석기 버전에서 이전 캐시를 한 번 다시 분석한다.

- 1·2·3·4·6·8·12·16마디 중 길이와 실제 비트 안정성에 맞는 후보를 비교한다.
- 비트를 맞출 수 있어도 원래 템포를 유지하는 인계를 함께 비교한다. 첫 다운비트 앞의 보컬을
  버리거나 과도한 템포 변화를 줄 때에는 자연스러운 인계가 우선할 수 있다.
- 첫 보컬, 측정된 섹션 경계, 지속적인 타격감 상승에 전환의 **끝**을 맞추는 후보도 만든다.
  추가 후보는 앞의 보컬을 생략하지 않는다. 나가는 곡의 마지막 소리와 소스 범위 보호는 유지한다.
- 실제 구간의 음량 공백/돌출, 저음 충돌, 가려지는 보컬, 동시 보컬, 조성 충돌을 비용으로 비교한다.
  다음 곡의 드럼이 전환 직후 들어오는 경우에는 그 구간도 음량·저음 기준에 포함한다.
  전환 양쪽 단독 재생의 음량도 별도로 비교 기준에 넣어, 페이드 양끝이 조용해도 전환 중 음량 저하를 평가한다.
  짧은 컷은 경계 주변 0.5초를 함께 평가하고 곡 끝의 마지막 한 마디 안에서만 자동으로 자른다.
- 저역·중역·고역 인계를 각각 조절한다. 고역은 점수가 좋은 EQ 후보에서만 추가로 탐색한다.
  중·고역 페이드가 음량을 추가로 떨어뜨리는지 확인할 때는 같은 큐와 저역 인계를 유지하고
  중·고역에 기본 페이드를 적용한 경우와 0.5초 단위로 비교한다. 기준 음량이 이미 낮거나 보컬이 겹치는 전환은
  중역 보정에서 제외한다. 음량 저하를 최소 1dB 줄이면서 최저 음량, 음량 돌출, 보컬과 리듬이 비슷한 경우에만
  중역 인계 위치를 조정하거나 최대 0.35초 늘린다.
  선택한 qsin EQ 구간은 기존 `band_windows`로 저장하므로
  미리보기·내보내기·수동 편집기의 전환 그림이 같은 계획을 사용한다.
- 곡별 볼륨, 베이스 설정과 EQ를 적용했을 때의 저역·중역·고역 전력을 추정해 전환을 비교한다.
  렌더러와 같은 필터 설정을 사용해 각 대역의 주파수 응답을 평균한다. 실제 소리의 세부 주파수 분포까지
  재현하는 계산은 아니다. [Audio EQ Cookbook](https://www.w3.org/TR/audio-eq-cookbook/)
- 전환 구간에 신뢰할 수 있는 박자가 양쪽 모두 있으면, 두 곡의 큐와 재생 속도를 적용한 위치에서
  가까운 박자끼리 비교한다. BPM이 같아도 킥이 엇갈릴 수 있고, 하프·더블 템포는 느린 쪽 박자가
  빠른 쪽과 맞물리는지 본다. 전환 상세에 박자 어긋남의 90백분위를 밀리초로 표시한다.
  대역별 전력과 페이드가 얼마만큼의 리듬을 남기는지도 함께 추정한다. 양쪽 리듬이 어긋난 채 겹치는 양을 줄일 수 있으면
  선택된 큐·길이·저역 인계를 유지하고 중·고역 인계만 조정한다. 보컬과 조성 충돌, 음량 저하와 돌출도 다시 확인한다.
- Sonara가 없어도 측정한 에너지/타격감으로 기존 프레이즈 컷·에코·자연스러운 엔딩 판단을 사용할 수 있다.
  절/후렴/드롭 등의 의미 라벨은 만들어 내지 않는다.
- 템포가 달라도 여러 길이의 페이드와 보컬 보호 EQ를 비교한다. 컷·에코·테이프 스톱은 타격감이 있고
  양쪽 곡에서 건너뛰게 될 구간이 보컬 없이 분석됐을 때 후보가 된다. 조건을 통과한 효과도 페이드와 비교한다.
- 대역별 측정값이 있으면 기본 페이드 길이 사이도 살핀다. 인계가 더 고른 후보가 근소한 점수 차를
  뒤집을 수 있다. 같은 시작·끝 큐를 유지하고, 가려지는 보컬·동시 보컬이나 음량·저역 과다가 커지는 후보는 제한한다.
- 곡 분석에 실패한 경계는 길이가 허용하는 범위에서 기본 크로스페이드를 적용한다. FFmpeg 기능이 부족해
  전환 효과나 음정 보정을 적용하지 못하면 실제 사용한 전환을 미리보기에 표시한다.
- 보컬이 미측정이면 긴 중역 오버레이를 피하고, 조성 충돌은 좁은 중역 인계로 보호한다.
  곡/구간의 측정값이 없으면 기존 보수적 선택으로 처리한다. 수동 큐·길이·스타일과 잠금은 우선한다.

비용은 학습된 청취 품질 확률이 아니다. 1초 음향 특징으로 렌더러의 페이드 전력을 예측하는 근사치이며,
보컬 분리는 EQ만으로 완벽하지 않다. 리듬 분석과 함께 안전한 후보를 고르는 데 사용하고,
사람의 청취를 대체하거나 전문 DJ 수준을 보증하는 수치로 표시하지 않는다.

검증: `python -m unittest tests.test_automix_intelligence`
실제 FFmpeg 검증은 `PLAYLIST_CANVAS_TEST_FFMPEG`에 실행 파일 경로를 지정한다.
로컬 음원 비교: `python tools/automix_listening_report.py OUT SONG1 SONG2 --ffmpeg PATH --compare`.
`comparison.json`과 `compare/`의 FLAC은 같은 곡 경계를 세 가지로 비교한다. `after`는 현재 AutoMix,
`before`는 현재 규칙에서 음향 점수 계산을 끈 결과, `crossfade`는 기본 크로스페이드다.
0.5초보다 짧은 전환도 실제 길이에 맞춰 측정하고, 겹침이 없는 컷은 경계 앞뒤 25ms씩 측정한다.
`handoff_dip_db`는 컷 주변도 포함해 가장 조용한 0.5초를 따로 기록하므로 길이가 다른 전환을 비교할 때 사용한다.
음량/저음 수치와 `ratings.csv` 청취 평점을 함께 확인한다. 생성 음원·보고서는 커밋하지 않는다.

재생목록의 EQ 전환을 블라인드로 듣는 명령은 `python tools/automix_listening_report.py OUT PLAYLIST.m3u8 --blind`다.
음원 파일을 직접 순서대로 전달해도 된다. `blind.zip`의 A/B는 큐·길이·템포·곡별 필터와 대역 분할을 공유하며,
한쪽은 AutoMix의 대역별 인계, 다른 쪽은 같은 위치의 기본 이퀄파워 페이드다.
압축 파일 안의 `ratings.csv`에 선호도를 기록한 뒤 별도 `blind-key.json`으로 어느 쪽이 AutoMix였는지 확인한다.
